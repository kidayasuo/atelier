# 第1講　建築物の構造設計

2026年9月30日／満田衛資。スライドの内容に、授業中の補足と背景を加えたまとめ。

## 1. 建築物と自然災害

建築物は、供用期間中に **地震・台風・大雪** などの自然の猛威にさらされる可能性が大いにある。

| 猛威 | 例 | 設計上の扱い |
|---|---|---|
| 地震 | 阪神・淡路大震災（1995.1.17） | 地震力 |
| 台風 | 平野神社の社殿倒壊（2018、京都市北区） | 風荷重 |
| 大雪 | 熊谷ドームの膜屋根崩落、旧富岡製糸場 乾燥場の倒壊（2014、関東） | 積雪荷重 |

- 阪神・淡路大震災では、死者の多くが建物の倒壊による圧死だった。被害は **1981年の新耐震基準** より前の建物に集中し、中間階だけが潰れる **層崩壊** やピロティ階の崩壊が目立った。
- 熊谷ドームは、積雪の重みで **膜が破れて** 崩落した。自重の小さい膜屋根や大スパンの軽い屋根は、想定を超える積雪に特に弱い。
- 平野神社の台風は、スライドでは「20号」。一般には2018年9月4日の台風21号として報じられている。

### 建築物の2つの役割

1. **倒壊防止**：人々の生命や財産を守る。**絶対条件**。
2. **機能維持**：生活やその基盤としての社会経済が停滞しないよう、官公庁・工場・流通・インフラ等の施設の機能を維持する。

したがって建築物は、自然の猛威に対して安全であることはもちろん、必要に応じて機能維持がなされるよう設計されなければならない。

> **授業の補足**：機能は、構造体が健全でも失われることがある。設備（電気・給排水・空調・エレベーター）や非構造部材（天井・外壁・ガラス）が壊れれば、建物は立っていても使えない。東日本大震災では天井の脱落で使えなくなった施設が多く、2014年に特定天井の基準ができた。

### 災害から学び、制度を改める

> **授業の補足**：実際の災害からわかることは多い。知見を累積し、制度を改める。その繰り返しが重要。災害だけでなく、事件も契機になる。

| 契機 | 制度の変化 |
|---|---|
| 1923 関東大震災 | 1924 市街地建築物法に初の耐震規定（設計震度0.1） |
| 1968 十勝沖地震 | 1971 RC柱の帯筋を強化 |
| 1978 宮城県沖地震 | **1981 新耐震基準** |
| 1995 阪神・淡路大震災 | 耐震改修促進法、2000 木造の接合部・壁配置の規定 |
| 2005 構造計算書偽装事件 | **構造設計一級建築士**、構造計算適合性判定 |
| 2011 東日本大震災 | 2014 特定天井の基準 |
| 2014 関東の大雪 | 2019 緩勾配・大スパン屋根の積雪荷重を割増 |

## 2. 建築の構造とは

> 建築の構造とは、**建築を支える骨格** であり、常時に作用する **重力** や **自然の猛威** に対し、建築が安定して存在し、その機能を果たし続けるために不可欠なものである。

外観からは見えなくても、建設中の写真ではトラスなどの架構が現れる。

## 3. 構造設計という職能について

設計チームは **意匠・構造・設備** の3分野からなり、構成には2つの型がある。

| | 専業型 | 組織型 |
|---|---|---|
| 形態 | 各設計事務所がそれぞれ独立した会社 | 同じ会社内に各部門がある |
| 例 | アトリエ建築家＋専業設計事務所 | 組織設計事務所、ゼネコン設計部 |
| 発注者との契約 | 通常は意匠設計事務所。構造・設備はその下で契約（構造設計事務所が発注者と直接契約する場合もある） | 会社として契約 |

### 「組織設計事務所」とゼネコン設計部

ゼネコンも組織なのに、「組織設計事務所」には含めない。分け方の軸が2本あるためである。

- **アトリエか組織か**：「組織設計事務所」は、建築家個人の名前と作家性で設計するアトリエ事務所に対し、大人数の所員と各分野を抱えて組織として設計する事務所を指す呼び名。
- **設計専業か設計施工一貫か**：慣用として、施工部門を持たない設計専業の大規模事務所（日建設計・日本設計など）に限る。ゼネコン設計部は設計施工一貫の側。

| | 組織設計事務所 | ゼネコン設計部 |
|---|---|---|
| 施工 | しない（設計施工分離） | 自社で施工（設計施工一貫） |
| 立場 | 発注者の側で工事監理 | 施工の知見を設計に織り込める |
| 強い領域 | 公共建築 | 工場・倉庫・オフィス・マンションなど民間 |

上下関係ではない。スライドの「組織型」は、さらに別の軸（意匠・構造・設備が同じ会社にそろうか）で分けているので、両者が同じ型に入る。

## 4. 一級建築士と構造設計一級建築士

### 建築士制度

> 建築基準法第5条の6、建築士法第3条：原則的に建築物の工事は、建築士の設計によらなければならない。
> （＝一定の建築物の設計は、建築士以外の人はしてはいけない）

建築士は **一級・二級・木造** の3種類。扱える規模（難易度）は 非建築士 ＜ 木造建築士 ＜ 二級建築士 ＜ 一級建築士。

> **条文番号は覚える必要があるか**：建築士試験の法規は法令集持ち込みの択一式で、番号の暗記は問われない。問われるのは「この規模は誰が設計できるか」という中身。ただ、どこにあるかを知っていれば法令集をすぐ引ける。

### 業務範囲（令和7年4月1日施行の現行値）

**高さ16m以下** の建物について：

| 構造 | 建築士不要 | 木造建築士以上 | 二級以上 | 一級のみ |
|---|---|---|---|---|
| 木造 | 1〜2階、100㎡以下 | 1〜2階、100㎡超〜300㎡ | 3階建て、または300㎡超 | 特定用途 500㎡超／一般用途 1000㎡超（平屋を除く） |
| 木造以外（RC・S等） | 2階以下、30㎡以下 | — | 300㎡以下 | **300㎡超** |

- **高さ16m超、または地階を除く4階以上** は、構造を問わず一級のみ。
- 特定用途：学校、病院、劇場、映画館、観覧場、公会堂、オーディトリアムを有する集会場、百貨店（不特定多数が集まる用途）。
- **木造と木造以外で閾値が大きく違う** 点に注意。

**改正で何が変わったか**：二級建築士の範囲が「高さ13m以下かつ軒高9m以下」から「階数3以下かつ高さ16m以下」に。軒高の条件がなくなり、**階数と高さ16m** で判定する形になった。スライドの表は改正前の値。

### なぜ建築士でなくても設計できる範囲があるのか

- 建築士法は **1950年**、建築基準法と同じ年にできた。当時の住宅は大工棟梁が経験と木割で建てるのが普通で、戦後の深刻な住宅不足の中、小さな建物まで資格者の設計を求めると供給が止まる。そこで小規模な木造は大工に開いたまま残した。木造の閾値が大きいのはその名残。
- ただし、資格が不要でも **基準法への適合は必要**。小規模木造は **4号特例** で確認時の構造審査も省略されてきたため、壁量不足が見過ごされやすかった。
- **2025年4月の改正** で、特例は平屋かつ200㎡以下に縮小された。一般的な木造2階建ても、構造の審査を受けるようになった。

### 構造設計一級建築士

> 建築士法第2条6項、同法第20条の2第1項：ある規模以上の建物の構造設計には、構造設計一級建築士の **関与** が必要。

- **関与** とは、次のどちらか。
  - 構造設計一級建築士 **本人が構造設計を行う**
  - 一級建築士が構造設計を行い、構造設計一級建築士が **確認しサインする**（法適合確認）
- 対象は、一級建築士でなければ設計できない建築物のうち、ルート2以上の構造計算が必要な規模のもの。
- **平成20年（2008年）にスタート**。2005年の構造計算書偽装事件（姉歯事件）を受けた2006年の建築士法改正で創設された。同時に設備設計一級建築士、構造計算適合性判定もできた。

### 構造設計一級建築士への道のり

| 段階 | 条件 | 最短年齢 |
|---|---|---|
| 一級建築士の受験 | 大学卒業時に指定科目の単位を取得（2020年から大卒1年目で受験可） | — |
| 一級建築士免許 | 試験合格＋実務経験（60単位で2年、50単位で3年） | 24歳（以前は25歳） |
| 講習の受講資格 | 一級取得後、**構造設計の実務5年以上** | 29歳 |
| 構造設計一級建築士 | 講習と修了考査に合格 | 30歳 |

一級建築士試験の合格率は約1割（令和2〜5年：10.6／9.9／9.9／9.9％）。講習の修了率は約3割（36.1／29.9／36.3／27.2％）。実務5年以上の人でも3〜4人に1人しか取得できない、希少価値の高い資格。

## 5. 構造設計と建築基準法

**構造設計＝様々な外乱に対して建物が安全であるように設計すること。**

そこから、外乱をどう設定するか、安全をどう確認するか、そもそも安全とは何か、という問いが生まれる。その最低限の答えとして国が定めたのが **建築基準法**。

> **法の目的（第1条）**：建築物の敷地・構造・設備・用途に関する **最低の基準** を定め、**国民の生命・健康・財産の保護** を図り、公共の福祉の増進に資する。
>
> スライドの「皆が好き勝手にしたら国家としての水準が揃わない」は、その結果として安全の水準が揃う、という側面の説明。それ以上の性能を求めるかは、設計者と発注者の判断。

### 建築基準法が定める構造設計上の主な事柄

1. **主要構造部に使える材料とその強度**：普通に使える材料は木・鉄（鋼）・コンクリート。特殊な構造方法に用いる材料として、アルミニウム、膜材、免震用ゴムなどもある。
2. **建物が耐えるべき外乱の決め方**：第2講（長期・短期、鉛直荷重）と第3講（地震力・風荷重など水平荷重）で扱う。
3. **計算の方法と安全とみなす基準**：計算方法は、建物の構造種別や規模ごとに定められている。

### 安全の判定：σ ＜ f

安全か否かは、**応答値** と **基準値** の比較で判定する。

- **σ（応答値）**：構造計算の結果としての **応力度**。**構造力学は、この σ を計算するために学ぶ。**
- **f（基準値）**：法で定められた **許容応力度**。**材料**（種類と強度）で決まり、長期・短期で異なる。

> **授業の補足：応力度の代表的な求め方**
>
> - 軸応力度 σ ＝ N／A（N：軸力、A：断面積）
> - 曲げ応力度 σ ＝ M／Z（M：曲げモーメント、Z：断面係数 ＝ I／y）
> - せん断応力度 τ ＝ Q／A（平均値。長方形断面の最大値は 1.5Q／A）
> - 軸力と曲げが同時にかかるとき σ ＝ N／A ± M／Z
>
> N・M・Q は部材内部の力で **応力**、それを面積あたりにした σ・τ が **応力度**。許容応力度も、引張・圧縮・曲げ・せん断ごとに定められている。

### 主要な構造種別

| 種別 | 特徴 | 用途・規模 | 授業 |
|---|---|---|---|
| **木造** | 伝統木造・軸組工法・2×4工法。環境負荷の点で最も効率が良い | 耐火性能や強度の観点から主に低層 | 構造設計学Ⅱ |
| **RC造**（鉄筋コンクリート） | 圧縮に強いコンクリートを鉄筋で補強。鉄骨造に比べて経済性が高く、耐久性・耐火性にすぐれる | 一般に梁スパン10m程度までの中低層 | 構造設計学1 |
| **S造**（鉄骨） | 引張力に強く、高強度の鋼材。火災に弱いので耐火被覆が必要 | 高層ビル、ロングスパン梁 | 構造設計学Ⅱ |
| **SRC造**（鉄骨鉄筋コンクリート） | 鉄筋コンクリートの中に鉄骨を挿入 | 高層ビル、ロングスパン梁 | （構造設計学1） |

> **授業の補足：なぜ木造は大規模化しにくいか**
>
> 木造以外は「足し算」ができる。RC造はコンクリートを一層ずつ打設して一体化でき、S造は溶接や高力ボルトで母材と同等の強度で接合できる。小分けにしたパーツを足してゆき、その場で一層ずつ作れる。
> 木造は継手・仕口で断面が欠け、**接合部で部材の強度を100%伝えられない**。近年は集成材やCLT、接合金物の発達で、中高層の木造も建てられるようになっている。

> **背景：RC・SRC・S と高層**
>
> RC造が高層に向かなかった主な理由は重さ。地震力は重さにほぼ比例し、下層の柱も太くなる。ただ高強度コンクリートの登場で、今では40〜60階のRC造タワーマンションも多い。
> SRC造は、鉄骨が引張と粘りを、コンクリートが座屈防止・耐火・剛性を補い合う、日本で発達した構造。手間とコストがかかるため、1990年代以降は減っている。
> 超高層は、オフィスなら **S造**（軽い、工期が短い、広い無柱空間）、住宅なら **高強度RC造**（揺れにくい、遮音性、コスト）が主流。
