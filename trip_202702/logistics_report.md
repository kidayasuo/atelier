## 2. 日程

2泊3日。空いている窓は**2月15日（月）〜19日（金）**と**2月24日（水）〜26日（金）**の2つです。

### 日程の候補

- **A** 2/15（月）〜17（水）
- **B** 2/16（火）〜18（木）
- **C** 2/17（水）〜19（金）
- **D** 2/24（水）〜26（金）

**A〜Cの方が雪が良く、量も多い。Dは避けたい。**長滝（気象庁アメダス、標高430m）の平年値で2月中旬と下旬を比べると、気温の差は1.2℃ですが、**最深積雪は74cmから54cmへ27%減り、1日あたりの降雪は約3割減ります**。スキー場より低い地点なので、量ではなく傾向として見てください。例えば周辺の雪遊び施設、牧歌の里のスノーラフトやポニーの馬そりは「2月下旬〜3月上旬で積雪状況により終了する場合がある」と書かれています。この傾向は暖冬で早まることが予想されるので、A-Cを候補とし、Dを予備とします。

## 4. 企画チームが手配する範囲

### まとめる価値があるのはレンタル。リフトは案内するだけ

| 費目       | 企画チームの仕事                                               | 理由                           |
| -------- | ------------------------------------------------------ | ---------------------------- |
| **宿**    | **予約と集金**                                              | 料金が非公表で交渉余地がある。まとめないと押さえられない |
| **レンタル** | 現地の板は**予約の取りまとめ**、京都のウェアは**在庫の確保と団体割引の確認**（どちらも支払いは各自） | サイズの在庫確保、団体割引                |
| リフト      | **買い方の案内**（購入は各自）                                      | 割引の多くが本人限定で代理購入できない          |
| 交通・食事    | 案内のみ                                                   | 各自                           |

**レンタルをまとめる価値は在庫の確保です。** 団体割引は効きません。

**京都のウェアの在庫を押さえる**。借りるのは各自ですが、人数を先にSKIDへ伝えて在庫を確保し、10セット以上の団体割引が使えるかを聞いておきます。受け取りと支払いは各自で、**柄もサイズも本人が店で選びます**（7章）。

**サイズの在庫**。身長・体重・足のサイズを事前に渡さないと、当日埋まっている可能性があります。初心者が一番詰まる手続きでもあり、申込フォームで聞いてしまえば本人は何も考えなくて済みます。

**団体割引は、19〜22歳にはほぼ意味がありません**。ダイナランドは15名以上でセット5,500→3,000円（平日）ですが、条件は「団体料金のリフト券（平日4,600円）を15名以上が使うこと」です。19〜22歳は若者応援割の3,000円の方が安いので、団体券に切り替えるとリフトで損をします（7章）。

→ **サイズを集める締切、SKIDへの人数連絡、現地レンタルの予約**が、宿の予約と並ぶAチームの主要タスクになります。

**リフトをまとめない理由は、選択の自由より前に、物理的に買えないことです。**19〜22歳割引は本人の身分証が必要で、鷲ヶ岳の「雪マジ」はアプリ画面が必要。水曜半額デーも本人購入。企画チームが代理で買うと、**これらが全部使えなくなります**。企画チームの仕事は、**宿を決めること**（それで宿泊者価格が決まる）と、**買い方を1枚にまとめて渡すこと**（10章）の2つです。

### 申込フォームで聞くこと

サイズだけでなく**何を持っているか**を聞いておくと、レンタルの数量と、その人がいくら払うことになるかが同時に決まります。

- 身長・体重・足のサイズ（レンタルの必須項目）
- スキー・スノーボードの経験（初めて／数回／慣れている）
- **3日目も滑るかもしれないか**（はい／いいえ。「はい」の人は板を2日分予約します。2章）
- **上下のウェア**：スキーウェアがある・買う予定／レンタルを希望
- 防水の手袋、長靴、ゴーグル、フリースか薄手のダウン：それぞれある／ない
- スキースクールを受けたいか
- **SKIDの「みんなで行く日」に来るか**（7章）

### ウェアは京都で借りる

**ウェアとゴーグルは、京都のSKIDで各自借ります。予約は企画チームが取りまとめます。** レンタルスキー＆スノーボード SKID（北区紫竹西南町70-11、075-493-1316、13:00〜21:00、火曜定休）は、大学から自転車で行ける距離です。課金されるのは現地にいる日数だけなので、出発の前日に受け取って帰った翌日に返せば3日分、**ウェア上下6,100円＋ゴーグル1,200円＝7,300円**です。現地で3日借りる（13,000〜15,000円）の半額以下です。

柄やサイズは本人が選ぶので、企画チームはまとめて借りません。企画チームがするのは次の3つです。

- 申込フォームで人数を集め、SKIDに在庫を押さえてもらう
- 10セット以上の団体割引が使えるかを聞く（14章）
- 「みんなで行く日」を1〜2回作る。任意参加で、初めての人は経験者に選び方を相談できます

水曜出発（日程C・D）では前日が定休日にあたるので、その場合の扱いをSKIDに確認します（14章）。返却が遅れるとその人の料金が日数分増えるので、案内には「帰った翌日中に返す」と明記します。

料金は掲載時点のものです。在庫と来季の料金を確認できるのは、営業が始まる11月です。確認が取れなければ、現地で借りる形に戻します。

## 10. 初心者の案内

### この旅行が、すでに解決していること

スキーには、行ったことがある人にしか見えない落とし穴がたくさんあります。

- **リフト券を高く買う。** 券種が10種類以上あり、平日・宿泊者・年齢で値段が変わります。19〜22歳は無料か半額になる制度がありますが、知らなければ使えません
- **ウェアを借りずに行く。** レインウェアで代用すると、転ぶたびに袖口と裾から雪が入ります
- **手袋を持たずに行く。** 小物だけ借りられないスキー場もあります（ダイナランド）。軍手はすぐ濡れます
- **スニーカーで行く。** スキーブーツでは雪の上を歩けません。板を外したあとに履く靴が要ります
- **昼に宿へ戻れない。** ゲレンデから宿へのシャトルは、11:00の次が13:00ということがあります
- **止まれないまま斜面に出る。** 本人も周りも危ない

**この旅行では、これを全部先に潰してあります。** 歩いてゲレンデに出られる宿を選び、リフト券は「これを買ってください」と1種類だけ示し、レンタルはサイズを預かってまとめて予約し、持ち物は一覧にし、止まり方は午前のうちにプロに習えるようにしました。

**初めての人にとっては、これが一番の参加理由かもしれません。**そして**二回目からは、自分たちで行けます**。付録Aに、今回選ばなかった行き方とそれぞれに向いている条件を残してあります。

**予算内に収める道が1つだけあります。** JAM場内の**ペンション星の子**（ゲレンデまで徒歩5分以内、6畳和室2〜4名、バス・トイレ共用）は2食付きで1泊8,000〜9,500円の水準です。これなら勝山でも4万円台に収まる計算ですが、**予約サイトで受付が停止中**で2027年2月の設定を確認できませんでした。勝山を残すなら、ここへの電話が最初の一手です。

## 14. 電話で聞くこと

### 電話の進め方

**値引きを求める必要はありません。** 必要なのは、公表されていない枠があるかを確かめることです。

**1. 最初に何者かを名乗る。** 「京都工芸繊維大学の学生で、学科の行事として2027年2月に15名、2泊3日を計画しています」。これで個人客の窓口から外れます。

**2. 日程と人数を先に出す。** 相手が在庫を見られる状態にしてから質問に入ります。

**3. 学生団体プランの有無を聞く。** **鷲ヶ岳高原ホテル レインボーには「学校関係者の方へ」という学生団体向けの案内があります**（合宿・林間学校・修学旅行向け、大広間や研修室つき。ただし「夏季を中心に」）。割引率も人数条件も公表されていないので、聞かないと分かりません。ヴィラ・モンサンには公表がないので「学生の団体で扱いが変わることはありますか」。

**4. こちらの条件を、頼まれる前に差し出す。**

- 平日
- **2泊**（1泊より宿の手間あたりの効率が良い）
- 代表者が一括で支払う
- 全員同じプランで揃える
- 食事は宿におまかせでよい

「手がかからない団体です」と伝わることが、実質的な交渉になります。

**5. 今日は決めないと明言する。** 「人数が固まっていないので本日は相談です。◯月に改めます」。仮予約の期限も自然に聞けます。

**6. 値段は最後に、聞き方を変えて。** 「安くなりませんか」ではなく「**この人数・この条件だと、どのくらいになりますか**」。

**期待しすぎないこと。** 宿代は1人29,600円で、5%引けても1,500円です。雪マジが3,000円、滑る日数が1日8,000円以上であることを考えると、交渉の効き目は一桁小さい。**学生団体プランの確認だけは必ず**、あとは情報収集に徹するのが良いと思います。

### 宿に共通

1. **2/15〜19と2/24〜26で、15名・2泊3日の空き**（候補A〜Dの4通り。2章）
2. **チェックイン前に着いたときの荷物の置き場所と着替え場所**（ヴィラ・モンサンは公式に案内あり。レインボーはフロントかロッカールームか）

4. **団体料金・学生団体プランはあるか。何名から適用されるか**

6. 部屋の定員構成。3名・4名・5名・6名の部屋がそれぞれ何部屋空いているか
7. **キャンセル規定**（無料キャンセルの期限、以降の料率）。仮予約はできるか、いつまで保持できるか
8. 支払い方法とタイミング

16. 滑走コース外で雪遊び（雪に寝転ぶ、雪だるま）ができる安全な場所

**送迎は、出してもらえるかだけを聞きます。** 料金の話はこちらから出しません。「有料でも構わない」と先に言うと、無料で出してもらえたかもしれない送迎に値段が付き、上限もなくなるためです。

- **無料と言われたら**、それで決まりです
- **有料と言われたら**、「おいくらになりますか」と金額だけ聞いて持ち帰ります。比べる目安はタクシーで、4台で片道約2万円（1人1,300円前後）です
- **できないと言われたら**、「ほかのお客さんはどうやって来ていますか」と聞きます。地元のタクシー会社や送迎業者を教えてもらえることがあります

送迎が出れば、1日目は正午過ぎに宿に着けます。3日目もSAでの待ちがなくなります。

### リフト券の団体割引と早割

ダイナランドの共通1日券は、**一般は平日も6,000円**です。団体割引（15名以上）で平日4,600円、土日祝5,400円になります（公式の団体申込書）。以前このレポートで「平日の通常価格4,600円」と書いたのは、この団体料金を一般料金と読み違えたものでした。

### スキーウェア以外を使う場合

「雨具なら持っている」という人がいます。**雨具は3段階あって、どれを持っているかで答えが変わります。**

|                           | 生地      | スキー        | 雪遊び     |
| ------------------------- | ------- | ---------- | ------- |
| スキー／スノボウェア                | —       | **問題なし**   | 問題なし    |
| 登山用ハードシェル（3〜5万円）          | 40〜80D  | **問題なし**   | 問題なし    |
| 登山用レインウェア（1.5〜3万円）        | 20〜40D  | **初心者なら可** | 問題なし    |
| 街用・自転車用の雨合羽（2,000〜5,000円） | 薄手・透湿なし | **不可**     | これで足ります |

分かれ目は**透湿性と生地の強度**です。安い合羽は内側が汗で濡れて結局冷えます。生地も薄く、スキーのエッジは刃物なので転んだときに切れる。登山用のレインウェアなら初心者の速度では持ちます。

**雨具で代用する人には、2つ足りません。**

**保温。** 雨具はシェルであって保温着ではありません。フリースか薄手のダウンを中に着ないと、雨具を着ているのに凍えます。

**裾。** スキーウェアのパンツには裾にスノーガードが付いていて、ブーツの上にかぶせて雪を止めます。レインパンツにはこれがありません。初心者はとにかく座るので、**ブーツの中が雪だらけ**になります。長めの靴下と、裾をブーツにかぶせて絞る工夫が要ります。上着のパウダースカートも同じです。

**買う場合。** スキー・スノボウェアの上下セットはワークマンの4,900円（2025-26モデル）からあり、1〜2万円が中心、ブランド品は3万円以上。登山用レインウェアをこのために買うのは割に合いません（上下で1.5〜3万円）。スキーウェアを買った方が安く、用途にも合っています。

### ウェアを現地で借りる場合

京都のSKIDが使えなかったときの代案です。

|           | 現地                       | SKID（京都）   |
| --------- | ------------------------ | ---------- |
| ウェア1日     | 5,000円                   | —          |
| ウェア2日     | 9,000円（鷲ヶ岳は10,000円）      | —          |
| **ウェア3日** | **13,000円**（鷲ヶ岳は15,000円） | **6,100円** |

小物はどちらでも別料金です（鷲ヶ岳は1点1日1,000円、ダイナランドはセンターハウスでは単品の貸出なし・BaboonでグローブのみOK、SKIDはゴーグル3日1,200円）。

鷲ヶ岳には複数日プランがないので、1日5,000円×日数になります。

現地で全部借りる場合と比べると、こうなります。

| 滑る日数 | 現地でフルセット（宿泊者割引後） | 京都でウェア＋現地で板（鷲ヶ岳） |
| ---- | ---------------- | ---------------- |
| 1日   | 10,000円          | 11,100円          |
| 2日   | 20,000円          | 16,100円          |
| 3日   | 30,000円          | **21,100円**      |

ダイナは板が1日500円高いので、右の列が500円ずつ上がります。

**現地で全部借りる形に戻すと、総額は鷲ヶ岳が56,260円、ダイナが55,460円**になります（ウェアが滑る日だけになるので、1日目と3日目は雪遊びの服装を別に用意することになります）。
