### 歴史を学ぶ意味

キーワードは **参照可能性**。歴史は現在の世の中を見るための訓練であり、「なぜこの形なのか」を **考える訓練** である。そこから、新しいカタチが生まれる秘密が見えてくる。

### 3つの建築類型

| 類型 | 誰のための建築 | 見どころ |
|---|---|---|
| **住宅** | 人間 | どのように形が決まるか。機能だけでなく **環境・社会・生業**。支配者層と被支配者層 |
| **寺院** | 仏 | 神聖な空間を、使う人間のためにどう作るか。各時代の最高技術で建てられる |
| **神社** | 神 | 外来思想である仏教にどう対応したか＝日本人の美意識 |

この三者が **影響し合う** のが面白さ。

- **仏教の変遷**（大まかに）：学問的（高度な哲学体系、政治とのつながり）→ 宗派的 → 公共機関的（江戸時代、寺が集落の戸籍を管理）。
- **神社建築** は神の降臨装置＝ **「仮住まい」** としての本質を持つ。神と人間の関わりが祭り。モノではない何かを、モノで表現している。

> **背景**：江戸時代の寺請制度では、人々はどこかの寺の檀家として登録され、寺が作る宗門人別改帳が戸籍の役割を果たした。

## 1. 最も原始的な建築：住居

現存する最古級の建築は、7世紀後半の **法隆寺金堂**（寺院）。しかし最も原始的な建築は **住居** であろう。原始的な住居は **土間床で小規模** だっただろう、とされる。

### 分類の4つの軸

| 軸 | 種類（古い順） |
|---|---|
| 床の位置 | **平地** → **竪穴** → **高床**（約5500年前、縄文前期〜） |
| 壁の有無 | **伏屋**（壁なし。屋根が地面まで下りる）→ **壁立** |
| 軸部 | **掘立柱**（相当古くから）→ **石場建・土台建**（6、7世紀〜） |
| 屋根 | **扠首（サス）構法**（相当古くから）→ **棟持柱（ウダツ）構法**（扠首より新しいか？） |

スライドの分類図は、床の位置と壁の有無を組み合わせて整理している（伏屋式平地住居、周堤式平地住居、壁立式竪穴住居、2重伏屋式竪穴住居 など）。葺き材は土葺と草葺。

### 軸部

| | 作り方 | 特徴 |
|---|---|---|
| **掘立柱** | 地面に穴を掘り、柱を立てて埋め戻す。地中は丸太のまま | 柱だけで自立する。腐りやすい |
| **石場建** | 礎石の上に柱。石にあわせて柱の下を削り、地面をよくつき固める | 自立しないので、建てるときに足場（仮の支え）が必要 |
| **土台建** | 礎石の上に土台を据え、その上に柱 | |

- **江川家住宅**（伊豆の国市韮山）は、大黒柱だけが掘立。地面と切れていない。
- **伊勢神宮の心御柱（しんのみはしら）** も掘立。

> **背景**：礎石建は、6世紀末の飛鳥寺など、仏教建築とともに大陸から伝わった。伊勢神宮は正殿の柱そのものも掘立で、式年遷宮によってその形式を受け継いでいる。

### 屋根

- **サス構法**：2本の材（扠首）を頂部（アタマギ）で組み、屋根を支える。トラス。移動生活のテントもこの形。
- **ウダツ構法**：棟持柱（ハシラ）で棟木（ムナギ）を支え、垂木（タルキ）を掛ける。
- サス＝縄文、ウダツ＝弥生、という説もある。

## 2. 竪穴住居と縄文時代

竪穴住居の遺跡は **旧石器時代後期** から現れる（このころ定住が始まったか？）。移動生活（テント＝サス）と簡易な定住（焼畑）の時代。例：椎木山遺跡（北九州市）、ハサミ山遺跡（藤井寺市）。

**縄文時代＝定住生活の始まり。**

| 時期 | 竪穴住居と集落 |
|---|---|
| 早期 | 浅い。直径2〜3mの円形。炉は屋外が多い |
| 前期 | 定住性が強まる（増改築、炉が屋内に）。関東は方形、近畿以西は円形。地域で土器も異なる＝文化背景が異なる |
| 中期 | 農耕生活（植物栽培、宗教的儀礼）。**環状集落**（中央に広場、周辺に貝塚）。円形・多角形、中央に炉 |
| 後期 | 小型化、地域差が拡大。方形（中部〜九州）、円形（東北〜関東）。東北が文化の中心か。関西は水田 |
| 晩期 | 寒冷化で人口減少。西日本に水田が広がる → 弥生時代 |

- **柄鏡形** の住居跡（敷石を伴う例が多い）は、住居ではないのでは、という説がある。
- **三内丸山遺跡**（青森）：縄文の大規模な竪穴建物・掘立柱建物。栗の栽培、酒造、翡翠や黒曜石の加工・交易の痕跡。

## 3. 高床建物

**縄文前期、東日本で** 現れる（以前は弥生時代からとされていた）。代表例は三内丸山遺跡。

### 床を支えるのは大変

先史時代の床を支える形式は、**差込柱・股柱・添柱・束柱・貫** の5つ。

**桜町遺跡**（富山、縄文中期〜後期）で **貫** の痕跡が見つかった。貫は鎌倉時代以降にしか使われていなかったと言われていたので、大発見。

- 材は **栗**。とても硬く、かつては鉄道の枕木にも使われた。
- 当時の道具（石斧）で実験すると、穴1つに5時間、1本の仕上げに1日かかった。

### 弥生時代

- 高床は **西日本に多い**。縄文時代に多かった東北・北陸は少ない（東日本から伝播したか、大陸から移入したか？）。
- **湿地帯（水田）** に建つため、柱の沈下を防ぐ工夫も。例：**柱根と根がらみ**（瓜生堂遺跡、東大阪市、弥生中期）。
- 復原図の例：**安国寺遺跡**（大分県国東市、弥生後期の高床住居と倉庫）、**登呂遺跡**（静岡市、弥生後期）。
- 竪穴住居は **方形平面が主流**（近畿は円形、中国・九州は併存）。

> **復元と復原**：言葉の違いに注意。一般に、失われた建物を資料から推定して建てるのが **復元**、残る建物を当初の姿に戻すのが **復原**。

## 4. 古墳時代（3世紀末〜7世紀頃）

- 竪穴住居は **方形平面**。炉の位置が **中央から壁側へ** ＝ **室内の使い分け**。
- 倉庫には **高床（掘立柱建物）**。
- **草刈遺跡**（千葉県市原市）：住居跡のゾーニング。床の硬さから使われ方を推定（図の I が最も硬い）。

> **背景**：5世紀ごろ、大陸から造り付けのカマドが伝わり、壁際に設けられるようになった。

## 5. 大規模建物（弥生中期から）

高床の性格の変化：**倉庫** → **礼拝の対象（穀霊信仰）** → **神社・神殿・支配者の邸宅** に？

稲作 → **共同体意識** → **公共施設**（水路、穀倉など）→ **富の蓄積** → 建築や集落の規模が大きくなる。

例：**三ツ寺遺跡**（群馬県高崎市）。古墳時代後期の **豪族居館**。濠で囲まれた区画に、大規模な掘立柱建物（主殿）が建つ。

### 身舎と庇

「柱が2列」＝ **「身舎・庇」構成** ＝ **構造と空間の一致**。**日本建築を通底する特徴。**

- **身舎（もや）** は建物の主要な役目、**庇** は付属的な役目。建物の構造と使い方が一体化していた。
- 庇の外にさらに付けるのが **孫庇**、別の小屋根として差し掛けるのが **もこし（裳階）**。
- 棟木に平行な材が **桁**、直交する材が **梁**。
- **梁間（はりま）** と **梁行（はりゆき）** の違いに注意。
