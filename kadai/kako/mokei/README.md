## 作るもの・作らないもの（相談のチャットの案、11-11。ユーザーがまだ決めていない所は「案」）

- 作る：
  - 架構：対の梁（梁の幅160×2本）・柱（300角）・頭（楕円の桁の穴）・ハンチ・軒への延長
  - 桁：東の桁・内の列（v−3.4）の桁は円弧、西の頭の短い桁は架構に直角
  - k15.5（柱の無い合わせ梁）と、その両端を受ける桁
  - 母屋：等高線（隣の梁の同じ割合の点を結ぶ水平の直線）に沿う。北西で扇に開く（案、`../kettei.md`の「考え中」）
  - 2階の床梁（南の2階建ての所、スパン11まで）
  - 基礎の台：ベタ基礎と地中梁（架構の線・柱の列の線）
- 部分だけ作る（案）：
  - 屋根の構面（合板）：1〜2スパンだけ張り、母屋の上に張ること・構面があることを見せる（全部張ると架構が見えない）
  - 耐力壁：西の面・北西の斜め・南北の妻を、薄い板で（片側だけ、または開口を抜いて）
- 作らない：間仕切り、遊具（吊り点だけ印）、仕上げ（一文字葺き・外壁の杉板）、窓の枠

## 1/50の大きさの目安

| 部材 | 実物 | 1/50 |
|---|---|---|
| 梁の幅（1本） | 160 | 3.2 |
| 梁のせい | 端500→真ん中400（k15、荷重から部品が決める） | 10→8 |
| 柱 | 300角 | 6 |
| 母屋 | 60×150 | 1.2×3 |
| 架構の間隔 | 3,000（東の線の上） | 60 |
| 棟・軒（梁の上端） | 8,150・4,650 | 163・93 |
| 西館の大きさ | 約30×17 m | 約600×340 |

数は11-11の時点。梁のせいなどは`../kettei.md`と部品の`table`を正とする。

## 形のデータの受け取り方（案、ユーザーと決める）

- 3dmはユーザーが持つ。Claudeは3dmを読まない・書き換えない（プロジェクトの決まり）。
- 架構の部材は、部品が平らな外形を押し出して作っている。レーザーには、この平らな外形（梁・柱の面の形、凹み・穴を含む）を、ユーザーがRhinoから書き出して渡す（DXFかSVG、1:1のmm）。模型係はそれを1/50にして割り付ける。
- 母屋・桁は、長さと端の角度の一覧（部品の`table`やCSV）から作れる。
