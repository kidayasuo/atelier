# Grasshopperの「架構」部品

`kakou.py`：架構kの梁（2枚の板）・東西の柱・2階の床梁を、一つの部品で作る（Rhino 8 Mac、Python 3のスクリプト部品）。接合はTamediaに倣う。

## 置き方

1. Grasshopperに「Script」部品を置き、Python 3にして、`kakou.py`の中身を貼る。
2. 入力を足して名前を付ける（名前は下の表のとおり、半角）。任意の入力は、足さなければ既定の値。
3. 出力を足して名前を付ける：`plates`・`cols`・`floors`・`ptE`・`ptW`・`ptM`・`axis`・`lines`・`table`・`log`。

| 入力 | 型・受け方 | 中身 | 既定 |
|---|---|---|---|
| `roof` | Brep・Item | 屋根の面（梁の上端の面）。A・B・C案はこれを差し替える | 必須 |
| `k` | float・List | 架構の番号（8〜18、15.5も可） | 必須 |
| `west` | Curve・Item | 西の柱の外の面＝外壁の内面の線（平面） | 必須 |
| `eave` | Curve・Item | 軒先の線（平面） | 外壁の内面から780 |
| `showCol` | bool・List | 柱を出すか（1つなら全部に、kと同じ数なら1本ずつ） | True |
| `mids` | str・List | 2階の床梁の上端の高さ（FLから、"3200"、無しは空）。kと同じ数か1つ | 無し |
| `FL` | float・Item | 床の高さ | 0 |
| `D`・`t`・`gap` | float・Item | 梁のせい・板の厚さ・光の筋の幅（＝柱の厚さ） | 800・90・180 |
| `colE`・`colW` | float・Item | 東・西の柱の幅（架構の向き） | 480・400 |
| `ha`・`hb` | float・Item | 頭の楕円の半幅・半高さ | 280・380 |
| `e` | float・Item | 桁の中心の、梁の下端からの高さ | 80 |
| `ext0`・`ext1` | float・Item | 軒への延長のせい（外壁の内面で・先で） | 240・120 |
| `Dm` | float・Item | 2階の床梁のせい | 400 |
| `csv` | str・Item | CSVを書くファイルの道 | 書かない |

単位はmm。座標は育ち舎のモデルと同じ（中心と向きは`sodachiya/model/build/south/uv.py`の定数）。

## 決めていること

- 架構kは背骨の円弧の中心からの放射の直線。u＝3(k−1)をv−0.9の線の上で測る。東の柱の芯は東の壁の内面v−1.05から柱の幅の半分の内（colE＝480でv−1.29）。西の柱の芯は`west`との交点から柱の幅の半分の内。
- 梁の上端は、屋根の面と各板の真ん中の鉛直面の交線を直線で近似する（2枚で上端が違えば、それぞれの直線）。直線からのずれは`table`の`fit_dev`。
- Tamediaの形（詳細図の寸法の比で）：
  - 桁は楕円200×400、穴は＋10。頭は桁を木180で包む楕円（a280・b380）。
  - 桁の中心は梁の下端から80上。頭は下端より約300下がり、下端とはR600のハンチでつながる。
  - 端の上は、上端の直線に接する丸み（傾いた半楕円）で頭へ回る。
  - 柱は1本の材で、2枚の板が挟む。頭の下でR600で広がって頭に取りつく（2階の頭では上下とも）。柱の上は板の外形の中で終わる。
- 西の端は頭と軒先への延長が一つの板（せい240→先で120、先は鉛直で軒先の線の0.1手前、丸み300でつなぐ）。
- 形はどれも、一つの平らな外形（穴は内の輪郭）をまっすぐ押し出した立体。
- 例外は`showCol`だけ。k15.5の一枚の梁、2階の床梁の受け方、桁そのもの（東の桁・西の短いピン）は、Bakeしてから手で直す／標準の部品で作る。

## 気になる所（試してから決める）

- 頭は柱の芯から280出るので、東の頭は東の壁の内面から約40、西の頭（2階の床梁）は約80、壁の中に入る。
- `e`＝80は、せい800の梁では頭が下端から大きく下がる（Tamediaの梁はせい約550）。天井高・西の軒の高さと合わせて見る。

## 返してほしいもの

エラーのときは`log`の文と、スクリーンショット1枚。
