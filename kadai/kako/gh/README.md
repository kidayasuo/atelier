# Grasshopperの「架構」部品

`kakou.py`：架構の線・柱の列・梁の上端の高さ・荷重から、一組の架構（対の梁2本・柱・2階の床梁）を作る（Rhino 8 Mac、Python 3のスクリプト部品）。梁のせいは荷重から部品が決める（11-11、ユーザー）。形はTamediaに倣う（`../tamedia.md`）。

## 置き方

版はコードの4行目の`VERSION`（直したときの日本時間）で、`log`の1行目にも出る。

1. Grasshopperに「Script」部品を置き、Python 3にして、`kakou.py`の中身を貼る。
2. 入力を足して名前を付ける（名前は下の表のとおり、半角）。任意の入力は、足さなければ既定の値。
3. 出力を足して名前を付ける：`spine`・`rays`・`plates`・`cols`・`floors`・`ptE`・`ptI`・`ptW`・`ptM`・`axis`・`lines`・`table`・`log`。

梁と柱の外形（楕円の頭・ハンチ・本体の和）は、shapely（Pythonの図形の道具）で2Dのまま足し合わせる。Rhinoの曲線の和は、接する所や重なる辺でよく失敗するため（11-11、k9〜k17がすべて「外形の和ができない」）。足し合わせた外形は、折れる所（20°以上）と長い辺（40 mm以上、直線のまま）で区切り、ほかはなめらかな曲線（3次、ずれ0.1 mm以内）に戻してから押し出す（11-11、ユーザー：細かいポリラインの横じまをやめる）。コードの頭の`# r: shapely==2.0.6`で、Rhino 8が初回に自動で入れる。入らないときは`log`の2行目が「Rhino の曲線の和」になり、元のやり方で試す。

食い込み（Tamedia、`../tamedia.md`）：梁は平らなまま、梁の幅（1本）の`keyR`（既定1/3）を柱の凹みに沈める。柱の凹みは梁の外形＋3（遊び）。ただし頭の下半分（赤道より下）は遊び0で、頭の下の縁が柱の肩にじかに載る（ユーザー 11-11）。柱は、芯（厚さ`col`−2×凹み）と両面の層（厚さ＝凹み、梁の形を2Dで抜いたもの）の3枚で、立体の差は使わない。層は分けたまま出す（ユーザー 11-11）。梁のあいだ（光の筋）は`col`−2×凹みで、結果として決まる。

## 確かめていること（11-11、ユーザー：エラーは繕わず根本から直す）

- 直線であるべき辺：2Dの外形で、直線の上に並ぶだけの点（ずれ1e-6 mm未満）を除き、直線の辺を1本の線に戻す。40 mm以上の辺は`LineCurve`（ちょうどの直線）。曲線にするのは、楕円・円弧・放物線から取った点の並びだけ（点をそのまま通る3次の曲線、間引かない）。
- 平らであるべき面：輪の曲線が閉じていて、平らで（`IsPlanar`）、自分と交わらず、輪どうしも交わらないことを、面を作る前に確かめる。押し出したあと、平らな面の数が「直線の辺の数＋上下2」になっているかを数え、違えば`log`に部材の名前と数を出す。
- できないときは、ポリラインなどで作り直さず、部材の名前（例：`k15柱1面+`）と理由（交わる所の座標など）を`log`に出して止める。
- 屋根の面が梁の面を覆っていなければ、延ばさずに止める（屋根の面を本来の縁まで描く）。
- 11-11に見つけて直した欠陥：
  - 外の端の頭の上（傾けた半楕円＋四角形）：四角形が蝶の形（辺が交わる）で片方が落ち、赤道に約6 mmの段があった。→赤道から鉛直の接線で立ち上がり、上端の直線に接する一つの曲線（`cap_pts`）に。
  - 梁の下端と頭の丸み（ハンチ）：放物線の下端を直線に置き換えて丸みを求めていたので、接点がずれて折れていた。→実際の下端の曲線に接する丸みに（`_haunch`）。
  - 軒への延長と頭の丸み：外形に無い楕円の下半分に接していた。→実際の頭の外形（楕円＋冠）に接する（`fillet_shape`）。
  - 楕円の点の取り方：上下左右の端の点を通らず、直線の辺とのあいだに小さな段ができた。→点の数を4の倍数に。
  - 曲線の区切りの点の間隔が不ぞろい（0.5 mmと20 mmが隣り合う）で、3次の曲線がはね返り、輪が自分と交わった（Rhinoで k9〜k17）。→等しい間隔に取り直し、弦の長さで結ぶ（`_resample`、`CurveKnotStyle.Chord`）。
  - 桁の穴：点から作った周期の曲線が閉じなかった。→ちょうどの楕円の曲線にして、その場所の部分に開ける。
  - 2つの曲線が小さな角度（3〜10°）で出会う所を、角として区切る（前後の点より大きく折れる点）。
  - 対の梁の頭の高さ：梁ごとに屋根の面から上端を取り、頭（桁の中心）もそれぞれの下端から決めていたので、左右の梁で頭が数mmずれ、柱の面の層に細い切れ端や穴ができた（Rhinoで k9〜k18、手元の再現で720例中122）。→桁は対の梁と柱を一直線に通るので、頭の高さは架構の線の上の梁にそろえ、上端だけをそれぞれの屋根の面に合わせる（720例中0）。

## 梁のせいを荷重から決める（11-11）

架構ごとに、梁を連続梁（支点＝柱の芯、柱の頭はピン。接合が剛かどうか確かでないので、鉛直の荷重には当てにしない、ユーザー 11-11）として解き、曲げ（長期12、雪は×1.6/1.1）とたわみ（長期×2と雪の大きい方、各スパンL/250）が足りるいちばん浅い端のせいを、25刻みで探す。長いスパン（4 m以上）の真ん中は端×`DmR`。`same`（既定）なら、全部の架構をいちばん深いものにそろえる。

ほかに確かめて`table`と`log`に出すもの（せいは決めない）：柱の座屈（全断面、両端ピン）、凹みのところの残りの断面、頭の肩の支圧（梁の繊維に直角、2本で2×凹み×柱の幅）。圧縮とめり込みの許容値は基本編に無いので、集成材の一般的な値（長期fc8.0・めり込み2.2、短期14.5・4.0 N/mm²）。1を超えたら`log`に「柱を太く・梁の幅を広く」などと出す。荷重は`qD`（屋根の固定）・`qS`（雪）・`sp`（間隔）と、吊り荷重`hang`。略算の検証：`../ryakusan/shin_1109.py`と同じ架構で、比と軸力が合う。

## 下書き（円弧と架構の線）

円弧と架構の線は、手で描かない。`k`だけをつなぐと、部品が下書きを出す（`roof`・`west`は要らない）：
- `spine`：西館の東の壁の外面の円弧（v−0.9）・東の柱の芯の円弧（v−1.20）・内の列の円弧（v−3.4）。
- `rays`：架構kの放射の線（v−0.9からv−17まで）。

Bakeして、屋根の面・外壁の内面の線・軒先の線を描く下敷きにする。座標は育ち舎の3dmと同じ（mm）。確かめ：k15の線はv−0.9で(−10451.0, −23171.6)、v−17で(−26488.1, −21750.4)を通る（育ち舎の3dmのu42の架構と重なる）。モデルの原点を動かしていたら、この点がずれる。

| 入力 | 型・受け方 | 中身 | 既定 |
|---|---|---|---|
| `frames` | Curve・List | 架構の線（平面の直線、始点が東の端）。無ければ`k`から放射の線 | 無し |
| `k` | float・List | 架構の番号（8〜18、15.5も可）。`frames`があれば名札だけ | `frames`か`k`が要る |
| `colLines` | Curve・List | 柱の列の曲線（柱の芯）。架構の線と交わる所に柱を立てる | 無ければ東v−1.05＋柱の半分・`vIn`・`west`から柱の半分 |
| `roof` | Brep・Item | 屋根の面（梁の上端の面）。A・B・C案はこれを差し替える | `roof`か`zE`・`zW` |
| `zE`・`zW` | float・List | 梁の上端の高さ（東と西の柱の芯で）。1つなら全部に、架構と同じ数なら1本ずつ | 同 |
| `west` | Curve・Item | 外壁の内面の線（平面）。軒への延長の始まり。`colLines`が無ければ西の柱もここから | — |
| `eave` | Curve・Item | 軒先の線＝屋根の面の縁（平面）。外壁の外の面（壁面後退の線）から780外 | 外壁の内面から980 |
| `hang` | str・List | 吊り荷重 "s:kN;s:kN"（sは東の柱の芯から西へm）。1つなら全部に | 無し |
| `qD`・`qS` | float・Item | 屋根の固定荷重・雪（kN/m²） | 0.84・0.6 |
| `sp` | float・Item | 架構の間隔（負担の幅、mm） | 3000 |
| `t`・`col` | float・Item | 梁の幅（1本、対で2本）・柱の幅（角材）。意匠で選ぶ | 160・300 |
| `keyR` | float・Item | 凹みの深さ／梁の幅（1本） | 1/3 |
| `DmR` | float・Item | 長いスパンの真ん中のせい／端のせい | 0.8 |
| `tipR` | float・Item | 柱の広がりの先の厚さ／梁のせい。広がりは遊び0で頭の縁に沿い、この厚さになる所で頭の縁に直角に切る（Tamediaの写真、11-11） | 0.04 |
| `D`・`Dm` | float・List | 梁のせいを手で決めるとき（部品は確かめるだけ） | 荷重から |
| `same` | bool・Item | 梁のせいを全部の架構でそろえる | True |
| `vU` | float・Item | uを測る円弧のv（m）。0＝本館の背骨 | 0 |
| `vIn` | float・List | 内の柱の列のv（m、`colLines`が無いとき）。列を無くすには0を一つ | 3.4 |
| `showCol` | bool・List | 柱を出すか | True |
| `mids` | str・List | 2階の床梁の上端の高さ（FLから） | 無し |

| `ext0`・`ext1` | float・Item | 軒への延長のせい（外壁の内面で・先で） | 240・120 |

`table`の列：k・sup（柱のs）・span_max・s_tip・slope_deg・topE・topW・De・Dm・hang・r_bend（曲げ）・r_defl（たわみ）・r_buckle（座屈）・r_notch（凹み）・r_shoulder（肩）・N_long・N_snow（柱の軸力kN、＋は圧縮）・gap（梁のあいだ）・fit_dev。

単位はmm。座標は育ち舎のモデルと同じ（中心と向きは`kadai/sodachiya/model/build/south/uv.py`の定数）。

## 決めていること

- 架構kは背骨の円弧の中心からの放射の直線。u＝3(k−1)を本館の背骨（v＝0）の上で測る（育ち舎の`uv.py`と同じ、ユーザー 11-09）。
- 柱の芯：東は東の壁の内面v−1.05から柱の幅の半分の内。内の列は`vIn`。西は`west`との交点から柱の幅の半分の内。
- 梁は内の列の上を途切れずに続く。4 m以上のスパンは、下端が端で深く真ん中で浅い放物線（Tamediaの梁のカーブ）。短いスパンは端のせい一定。
- 梁の上端は、屋根の面と梁（1本ずつ）の真ん中の鉛直面の交線を直線で近似する（2枚で上端が違えば、それぞれの直線）。直線からのずれは`table`の`fit_dev`。
- Tamediaの形は、寸法を写さず、詳細図の比で支点の所のせいDから決める（ユーザー 11-09）：
  - 桁は楕円180×260（柱の幅の0.6）、穴は＋10。桁の中心は下端から0.14D。
  - 頭は半幅0.58D・半高さ0.68Dの楕円で、下端より下がる（穴のまわりに木120以上）。ハンチの丸み1.1D。
  - 外の端の上は、上端の直線に接する丸み（傾いた半楕円）で頭へ回る。
  - 柱は角材で、対の梁2本が挟む。頭の下で丸み0.55Dで広がり、頭の中では頭の形いっぱい。柱の上は梁の外形の中で終わる。
  - 食い込み：平らな梁が幅（1本）の1/3を、柱の両面の梁の形の凹みに沈める（Tamediaの詳細図・写真・分解図、ユーザー 11-11）。頭の下の縁が柱の肩に載る。
- 西の端は頭と軒先への延長が一つの部材（せい240→先で120、先は鉛直で軒先の線の0.1手前、丸み300でつなぐ）。
- 梁と柱は層ごとの立体のまま出す（立体の和・差は使わない）。
- 形はどれも、一つの平らな外形（穴は内の輪郭）をまっすぐ押し出した立体から作る。
- 例外は`showCol`だけ。k15.5の一枚の梁、桁そのもの（東の桁・西の短いピン）は、Bakeしてから手で直す／標準の部品で作る。

## 気になる所（試してから決める）

- 頭は柱の芯から0.58D出るので、東西の壁の中に入る。内側なので構わない（ユーザー 11-09。外へ出るのは妻の側だけ）。
- 2階の床梁は、屋根の梁と同じ支点（東・内の列・西）に掛ける。

## 返してほしいもの

エラーのときは`log`の文と、スクリーンショット1枚。

## 屋根の部品 `yane.py`（11-11）

屋根の面（梁の上端の面）を案の名前と高さから作り、出力`roof`を架構の部品の`roof`につなぐ。架構の線ごとに、東の縁（v−0.9の円弧）から軒先の線（`eave`）までの直線を引き、両端の高さを案で決めて、直線でつなぐLoftで面にする。南北の端の架構の外へ`gable`だけ延ばす。

| 入力 | 型・受け方 | 中身 | 既定 |
|---|---|---|---|
| `k` | float・List | 架構の番号（架構の部品と同じ） | 要る |
| `eave` | Curve・Item | 軒先の線（架構の部品と同じ） | 要る |
| `plan` | str・Item | `A`・`B`・`C` | `A` |
| `zE`・`zW` | float・Item | 東の縁・軒の梁の上端の高さ | 8150・4650 |
| `vE` | float・Item | 東の縁のv（m） | 0.9 |
| `kB` | float・Item | B案の境の架構（ここまで軒の高さ一定） | 軒の線の向きが3°変わる手前 |
| `slope` | float・Item | C案の勾配（°） | 南西の辺の軒がどこも`zW`以下になるいちばんゆるい勾配 |
| `kRef` | float・Item | C案の勾配をA案と同じにする架構 | 無し |
| `gable` | float・Item | 南北の端の架構の外へ延ばす長さ（東の縁で） | 1000 |

出力：`roof`（Brep）・`lines`（架構ごとの直線、南北の外の2本を含む）・`table`（k・L・両端の高さ・勾配・軒の線の向きの変化）・`log`。

- A案：東の縁と軒がどれも水平。架構のあいだは双一次（ねじれた）面。
- B案：南西の辺（西の直線の軒）にかかる架構はA案と同じ。その北は、境の架構の勾配のまま一定。
- C案：どこも勾配一定の円錐の面。架構の線は円錐の母線なので、架構のあいだは平らな面になる。既定の勾配は、南西の辺（B案と同じ見分け方）の軒がどこも`zW`以下になるいちばんゆるい勾配。南西の辺のほかの架構の軒は`zW`より低くなり、北は上がる。気にするのは南西の辺の軒の高さだけで、北は上がってよい（北の道は広く、向かいは大学、ユーザー 11-11）。`kRef`にk15を渡すと、A案でいちばんゆるいk15の勾配になり、ほかの軒はどれもA案より高くなる。
