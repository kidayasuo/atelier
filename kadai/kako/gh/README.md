# Grasshopperの「架構」部品

`kakou.py`：架構kの梁（2枚の板）・柱（東・内の列・西）・2階の床梁を、一つの部品で作る（Rhino 8 Mac、Python 3のスクリプト部品）。Tamediaに倣う（2026-11-09夜に作り直し、図は`../zu/shin_1109.pdf`）。

## 置き方

版はコードの頭の`VERSION`（日時）で、`log`の1行目にも出る。直すたびに書き換える。

1. Grasshopperに「Script」部品を置き、Python 3にして、`kakou.py`の中身を貼る。
2. 入力を足して名前を付ける（名前は下の表のとおり、半角）。任意の入力は、足さなければ既定の値。
3. 出力を足して名前を付ける：`spine`・`rays`・`plates`・`cols`・`floors`・`ptE`・`ptI`・`ptW`・`ptM`・`axis`・`lines`・`table`・`log`。

板と柱の外形（楕円の頭・ハンチ・本体の和）は、shapely（Pythonの図形の道具）で2Dのまま足し合わせる。Rhinoの曲線の和は、接する所や重なる辺でよく失敗するため（11-11、k9〜k17がすべて「外形の和ができない」）。足し合わせた外形は、折れる所（20°以上）と長い辺（40 mm以上、直線のまま）で区切り、ほかはなめらかな曲線（3次、ずれ0.1 mm以内）に戻してから押し出す（11-11、ユーザー：細かいポリラインの横じまをやめる）。コードの頭の`# r: shapely==2.0.6`で、Rhino 8が初回に自動で入れる。入らないときは`log`の2行目が「Rhino の曲線の和」になり、元のやり方で試す。

食い込みも立体の差・和を使わず、層を重ねて作る（11-11、柱の立体の差がすべて失敗したため）。柱は、芯（欠き込みの奥、厚さ300−2×50）と両面の層（厚さ50、頭の形を2Dで抜いたもの）の3枚。板は、板（160）と内の面のキー（頭の形、50）。層は分けたまま出す（ユーザー 11-11）。

端の架構（k8・k18）の外の板は、架構の線から230外の面にあり、屋根の面の外に出ることがある。そのときは、架構の線と内の板の上端から延ばす（`log`に書く）。

## 下書き（円弧と架構の線）

円弧と架構の線は、手で描かない。`k`だけをつなぐと、部品が下書きを出す（`roof`・`west`は要らない）：
- `spine`：西館の東の壁の外面の円弧（v−0.9）・東の柱の芯の円弧（v−1.20）・内の列の円弧（v−3.4）。
- `rays`：架構kの放射の線（v−0.9からv−17まで）。

Bakeして、屋根の面・外壁の内面の線・軒先の線を描く下敷きにする。座標は育ち舎の3dmと同じ（mm）。確かめ：k15の線はv−0.9で(−10451.0, −23171.6)、v−17で(−26488.1, −21750.4)を通る（育ち舎の3dmのu42の架構と重なる）。モデルの原点を動かしていたら、この点がずれる。

| 入力 | 型・受け方 | 中身 | 既定 |
|---|---|---|---|
| `roof` | Brep・Item | 屋根の面（梁の上端の面）。A・B・C案はこれを差し替える | 必須 |
| `k` | float・List | 架構の番号（8〜18、15.5も可） | 必須 |
| `west` | Curve・Item | 西の柱の外の面＝外壁の内面の線（平面） | 必須 |
| `vU` | float・Item | uを測る円弧のv（m）。0＝本館の背骨（育ち舎の`uv.py`・3dmの架構と同じ） | 0 |
| `vIn` | float・List | 内の柱の列のv（m、正の数）。列を無くすには0を一つ | 3.4（2階の柱の線） |
| `eave` | Curve・Item | 軒先の線＝屋根の面の縁（平面）。外壁の外の面（壁面後退の線）から780外（軒樋まで900、敷地の境の100手前） | 外壁の内面から980 |
| `showCol` | bool・List | 柱を出すか（1つなら全部に、kと同じ数なら1本ずつ） | True |
| `mids` | str・List | 2階の床梁の上端の高さ（FLから、"3200"、無しは空）。kと同じ数か1つ | 無し |
| `FL` | float・Item | 床の高さ | 0 |
| `D`・`Dm` | float・Item | 梁のせい：支点の所・長いスパン（4 m以上）の真ん中 | 500・400 |
| `t`・`col` | float・Item | 板の厚さ・柱の幅（角材、＝2枚のあいだ＝光の筋） | 160・300 |
| `key` | float・Item | 食い込みの深さ（片側） | 50 |
| `Df` | float・Item | 2階の床梁のせい | 400 |
| `eR`・`haR`・`hbR` | float・Item | 桁の中心の下端からの高さ・頭の半幅・半高さ（どれもDに対する比） | 0.14・0.58・0.68 |
| `ext0`・`ext1` | float・Item | 軒への延長のせい（外壁の内面で・先で） | 240・120 |
| `csv` | str・Item | CSVを書くファイルの道 | 書かない |

単位はmm。座標は育ち舎のモデルと同じ（中心と向きは`kadai/sodachiya/model/build/south/uv.py`の定数）。

## 決めていること

- 架構kは背骨の円弧の中心からの放射の直線。u＝3(k−1)を本館の背骨（v＝0）の上で測る（育ち舎の`uv.py`と同じ、ユーザー 11-09）。
- 柱の芯：東は東の壁の内面v−1.05から柱の幅の半分の内。内の列は`vIn`。西は`west`との交点から柱の幅の半分の内。
- 梁は内の列の上を途切れずに続く。4 m以上のスパンは、下端が端で`D`・真ん中で`Dm`の放物線（Tamediaの梁のカーブ）。短いスパンは`D`一定。
- 梁の上端は、屋根の面と各板の真ん中の鉛直面の交線を直線で近似する（2枚で上端が違えば、それぞれの直線）。直線からのずれは`table`の`fit_dev`。
- Tamediaの形は、寸法を写さず、詳細図の比で支点の所のせいDから決める（ユーザー 11-09）：
  - 桁は楕円180×260（柱の幅の0.6）、穴は＋10。桁の中心は下端から0.14D。
  - 頭は半幅0.58D・半高さ0.68Dの楕円で、下端より下がる（穴のまわりに木120以上）。ハンチの丸み1.1D。
  - 外の端の上は、上端の直線に接する丸み（傾いた半楕円）で頭へ回る。
  - 柱は角材で、2枚の板がじかに挟む。頭の下で丸み0.55Dで広がり、頭の中では頭の形いっぱい。柱の上は板の外形の中で終わる。
  - 食い込み：板の頭（楕円）がまるごと柱に食い込む（Tamediaの写真、ユーザー 11-09）。板の内の面に頭の形の突起（深さ`key`）、柱の両面に同じ形の欠き込み（＋3）。頭の下の縁が柱の肩に載る。
- 西の端は頭と軒先への延長が一つの板（せい240→先で120、先は鉛直で軒先の線の0.1手前、丸み300でつなぐ）。
- 板はキーと一つの立体（立体の和）、柱は欠き込みを引いた立体（立体の差）。和・差ができなければ別の部品のまま出し、`log`に書く。
- 形はどれも、一つの平らな外形（穴は内の輪郭）をまっすぐ押し出した立体から作る。
- 例外は`showCol`だけ。k15.5の一枚の梁、桁そのもの（東の桁・西の短いピン）は、Bakeしてから手で直す／標準の部品で作る。

## 気になる所（試してから決める）

- 頭は柱の芯から0.58D出るので、東西の壁の中に入る。内側なので構わない（ユーザー 11-09。外へ出るのは妻の側だけ）。
- 2階の床梁は、屋根の梁と同じ支点（東・内の列・西）に掛ける。

## 返してほしいもの

エラーのときは`log`の文と、スクリーンショット1枚。
