# 全熱交換の換気：機器は西の帯の床下、外気と排気の口は越屋根、大きな前置きのフィルター、冬と夏の昼だけ

ユーザー（10-29 13:59）：全熱交換の換気はどこで？ → 越屋根の近くで汚れた空気を集め、外気もそこから（ユーザーの案）。メンテナンスを少なく（フィルターの掃除を楽に、少なく）。決定事項（共通）の「換気の道」の後に一行書いた。

**本館係・西館係（知らせ）**：ユーザー（10-29 13:59）：**プレゼンで質問されたときの用意なので、モデルに反映する必要はない**。3dm・図・決定事項_本館には入れない。質疑での答えは次の形：
1. **機器は西の帯の床下**：床下の空調機（6台、スパンのまとまりごと）と同じピットの脇に、天井埋込み型相当の全熱交換器をまとまりごとに（台数は換気量で決めてよい）。フィルターの掃除は西の吹き抜けの床の点検口から、しゃがんで数分（脚立なし）。
2. **外気と排気の口は越屋根**：越屋根の東の口のガラリの区画（換気扇の吐き出し 50d と同じ考え）に、外気の取り入れと排気の口。冬に越屋根のすき間を閉じても、この口は開いたまま（別の区画）。屋根の面には何も出さない（軒を細く見せる決まりを守る）。
3. **ダクト**：排気は梁間の高い所（越屋根の下）で集めて、外気とともに西の壁（v1.6）に沿った縦のダクト二本で床下の機器へ。熱を受けた新しい空気は床下の空調機へ入れ、床のスリットから出す（冬は暖めてから出る）。
4. **前置きのフィルター**：越屋根の外気の口に、目の粗い大きな前置きのフィルター（虫・花粉・ほこり）。機器のフィルターの汚れを遅くし、掃除を年に数回に。
5. **動かすのは冬と夏の昼だけ**（窓・越屋根を閉じる時）。春・秋と夏の夜は止める。

西館（遊戯室・はれのま・キッチン）も同じ考え（キッチンは区画を分けて別系統）。
