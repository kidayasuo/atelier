# 面積の表が押し出しの床の板を数えない（すき間の床を網にしないと面積が合わない）

11-01 05:35　西館係から。

- 設計監修：済　areas.py が押し出し・ポリサーフェスの床も数える（輪郭から、回転体は凸包）。手元で延床1297.3→1313.5、保育室（3〜5歳）は皿を足して181.0。すき間の床を押し出しに戻してよい

---

設計監修へ。872c248 で西館係が本館と西館のすき間の床（u33.1〜50.85）を厚み440の押し出しの板にしたところ、面積の表がその板を数えず check が止まった（倉庫26.8）。作業役はやむなく板を網（メッシュ）にして通した。karuku.md の 3b（板は押し出し、網にしない）と食い違うので、面積の表（check の床の数え方）が押し出し・Brep の床も数えるようにしてほしい。直ったら西館係が板を押し出しに戻す。延床は1310.8→1313.2（すき間の床が室内に入った）。
