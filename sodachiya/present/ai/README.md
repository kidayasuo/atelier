# Illustrator の割付（育ち舎のプレゼン）

`present/mock.py` を走らせると、このフォルダに `layout.json`（5枚の部品と位置）と `parts/`（ページの残りの絵）ができる。
Illustrator のスクリプトで、それを部品ごとに動かせる .ai に組む。木田さんが動かしたり書き換えたりした割付は、
`layout_user.json` に書き出して push すると、次の更新から mock.py がそれをもとにする。

## 部品

| 種類 | レイヤー | 中身 |
|---|---|---|
| 枠 | 枠 | 外枠・上の帯の線・表題・右下の名前。シンボル「枠」（全ページ共通。シンボルパネルの「枠」をダブルクリックして直すと全ページに効く） |
| 図 | 図 | 素材（`present/sozai/`）とほかの係の図（`drawings/`・`out/`）をリンクで配置。切り抜いて使う図はクリップグループ。いちばん下は「その他の絵」（縮尺・方位など、`parts/pN_その他.pdf`） |
| 線 | 線 | 引き出し線（線＋端の点のグループ） |
| 説明 | 説明 | 文字（ポイント文字）、説明の箱と見出し・本文（本文はエリア内文字）、設計趣旨、ページとサブタイトル |
| 注記 | 注記 | 割付の注記（紫）。見えるが印刷しない。要らなければレイヤーごと隠す |

文字はヒラギノ角ゴシック（W3・W6）。段落は両端揃え（最終行は左）、一字下げなし、行送りは文字の1.5倍、段落のあいだは1行分。

部品の名前（レイヤーパネルに出る）と、部品の「メモ」（属性パネル）にある `sdy:…` の印でつながっている。**印を消さない**（消すとその部品は更新されない）。

## 使い方

1. **はじめて組む**：Illustrator → ファイル → スクリプト → その他のスクリプト… → このフォルダの `build_sodachiya.jsx`。
   新しいドキュメントができて `sodachiya_present.ai` に保存される（すでにあれば日時の付いた名前で保存、上書きしない）。
2. **割付する**：部品を動かす・大きさを変える・文字を書き換える・要らない部品を消す。自分で足す物（描き足し・写真など）は自由に足してよい（印の無い物はスクリプトが触らない）。
3. **割付を渡す**：ファイル → スクリプト → その他のスクリプト… → `export_layout.jsx`。`layout_user.json` ができるので、atelier のフォルダで
   `git add sodachiya/present/ai/layout_user.json`・commit・push。
4. **素材や文が新しくなったとき**：git pull してから、.ai を開いたまま `update_texts.jsx`。文字を新しい文に、リンクを読み直し、
   新しい部品を足す（位置は動かさない。書き換えた文字・消した部品は 3 の書き出しのとおり残る）。リンクだけなら Illustrator の「リンク」パネルの更新でもよい。

## 箱と引き出し線（10-25）

- 説明の箱は、箱・見出し・本文が一つのグループ（箱の名前）。箱をドラッグすれば文字もいっしょに動く。文字だけ直すときは文字ツールでそのままクリック、グループの中の一つだけ動かすときはダブルクリックで中に入る。
- 前に組んだ .ai は、一度だけ `group_boxes.jsx` を走らせるとまとまる（新しく組んだ .ai はもうまとまっている）。
- Illustrator には線を箱につなぎっぱなしにする仕組みが無いので、箱を動かしたら `reconnect_leaders.jsx` を走らせる。線の終わり（点）はそのままで、始まりを箱の縁の点に近い側へ付け直す（まっすぐな一本の線になる。折れを付けたいときは手で）。点の位置を変えたいときは、線のグループの中の点を動かしてから走らせる。

## 配置図の中の部品（10-25夕）

- 配置図は、3dmから描いた三つ（色・線・文字）のリンクが土台。そのうえに、配置図の中の文字（建物・園庭・道の名前と注）、注の線、突き出た木（枝の円と幹の点）を一つずつの部品として置く（レイヤー「説明」）。注の文字と線は一つのグループ（「配置図の注　…」）、突き出た木は「突き出た木」のグループ。グループごと動かすか、ダイレクト選択ツールで線の端だけ動かす。
- `01c_配置図_1-200_文字.pdf` は空になった（リンクが切れないように、ファイルは残す）。
- 前に組んだ .ai は、git pull のあと `update_texts.jsx` を一度走らせると、新しい部品が足され、配置図の三つのリンクが読み直される（位置は動かさない）。

## 木田さんが足した物（10-26）

- 部品の印（`sdy:`）の無い物は「木田さんの物」。スクリプトは中身を変えない。
- `export_layout.jsx` は、木田さんの物も `layout_user.json` の `user_items` に書き出す（種類・名前・レイヤー・アートボード・位置と大きさ・線と塗りの色・太さ・不透明度・パスの点・文字）。プレゼンの準備はこれを読んで、何が足されたかを知り、見本のPDFにも描く（矢じり・線幅のプロファイルなどIllustratorだけの体裁は見本には出ない）。
- `build_sodachiya.jsx` で組み直すときは、前の `sodachiya_present.ai` を開いて、木田さんの物を新しい .ai の同じレイヤー・同じアートボードの同じ位置へ写す（矢じりなども含めてそのまま）。組み直す前に .ai を保存しておく。

## 決まり

- 座標は mm、アートボードの左上が原点（下へ y）。ポイント文字の x,y は文字の基準線の始まり（右寄せ・中央は揃えの点）。
- ユーザーが書き換えた文字は `layout_user.json` の `s`（元の文と違うときだけ書く）。mock.py の文が後で変わっても、書き換えた所はユーザーの文が残る。
- 見本の `sodachiya/presentation.pdf` は mock.py の既定の割付のまま（ユーザーの割付は .ai と `layout.json` に入る）。

## 図面の文字と寸法（10-29）
- 課題の要求の図面（2枚目の立面図二つ、3枚目の断面図Cと縦断面図A、4枚目の平面図）は、図ごとに一つのグループ（レイヤー「図」、名前は「立面図　園庭の側」「立面図　道路の側」「断面図C」「縦断面図A」「平面図」）。中は、いちばん下に図の線のリンク（切り抜きのグループ、文字と寸法は入っていない）、その上に文字と寸法の部品が一つずつ。
- 部品の分け方：寸法は一つずつ「寸法　3,147　本館の軒の高さ」のグループ（寸法線の一区間・両端の補助線と斜線・数字。続き寸法は区間ごと）。ほかは「高さ　GL　−300」（記号と値）、「通り芯　5」（丸・番号・線）、「部屋名　ホール　75.2 m²」（名前と面積）、「断面の位置　C　C」、「図名　…」、「注　…」、文字の無い「線」（地盤の線・図枠など）。一つしか無い物（字だけの注など）はグループにせず、そのまま。
- **図ごと動かす**：選択ツール（黒い矢印）で図をクリックしてドラッグ。中の部品も一緒に動く。
- **一つだけ動かす・消す**：図をダブルクリックして中に入り、寸法などのグループをクリックして動かす（Deleteで消す）。グループの中の一つ（数字だけ・線だけ）は、もう一度ダブルクリックして中へ。ダイレクト選択ツール（白い矢印）でもよい。終わったらEscか、何も無い所をダブルクリック。
- **文字を直す**：文字ツールでそのままクリックして書き換える。
- 直したら`export_layout.jsx`→`layout_user.json`をpush。次のbuild・updateでも、動かした位置・消した物・書き換えた文字はそのまま。
- 線のリンクは、自動の図なら`ai/parts/<紙の名前>_線だけ.pdf`（mock.pyが、文字の層`drawings/<紙の名前>_文字.pdf`と同じ線と文字を自動の図から抜いた写し）、Rhinoの図があれば`drawings_rhino/<紙の名前>.pdf`。文字と寸法の部品は、どちらも文字の層から作る（書体はヒラギノに替わる。字は真ん中で揃えてあるので、幅が少し変わっても真ん中は同じ所）。
- **図が新しくなったとき**（更新係の作り直し・Rhinoの図）：git pullして`.ai`を開いたまま`update_texts.jsx`。線のリンクを読み直し、形の変わった線の部品は作り直し、新しい部品を足し、図から無くなった部品は外す（動かしてある部品は、書き出してあればその位置）。図の大きさは変わらないのでbuildは要らない。
- 前に組んだ`.ai`は、git pullのあと`update_texts.jsx`を一度：図のリンクが線だけの写しに替わり（Rhinoの「文字と寸法」のリンクは外れる）、文字と寸法の部品が足されて、図ごとのグループにまとまる。

## 足した物（10-29 14:24：buildで消えない）
- 木田さんが.aiに足した物（印の無い物、どのグループの中でも）は、export_layout.jsxで`layout_user.json`の`user_items`に入り（一つずつ印`sdyu:<鍵>`）、これが正本。build_sodachiya.jsxはuser_itemsから描き直し（配置図の上の物は配置図と一緒に動いて「配置図（まとめ）」へ）、前の.aiからは書き出していない物だけを写す。update_texts.jsxも.aiに無いuser_itemsを足す。消したいときは.aiで消してから書き出す（消えた物は`deleted_user`に移り、描かれない）。足したらbuildの前に書き出す。
