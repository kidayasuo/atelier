# 西館の架構の点検（10-28夜、設計監修。build e62cc99 の3dm）

**結論**：架構の形は段7c（`south/fix_details.py`の「西館の架構」の節）の後で変わっていない。7f clip_parts・7g/7h・9・10 clean_wire は架構の130物を変えていない（s7c と sodachiya.3dm で全物の bbox と体積が一致）。生成の段（`run_exact_new.py`の西館）が持ち込むのは F・G だけで、ほかは7cで生まれる。7cは穴のある押し出しを桁と関係なく別々に動かしている（Phase 1 平行移動、2 move_xy、3b、3d、3e の`_deepen`と`_head`）。

単位はm・mm。t は架構の面に直角な方向（柱 t∈[−90,90]、板 [90,180]・[−180,−90]）。

## 欠陥
- **A. 西の接合部で、梁の板の穴が桁の上150**（u24〜48、v−12.4〜−14.7、z≈4.23k）。22bの穴の中心が桁の中心より+145〜+155。原因：`_deepen`の`P[:,2] += mean(zr_-zt)`が穴も屋根の面まで上げるが、桁22dは動かさない。直し：穴は元の深さのまま（または桁を同じだけ上げる）。
- **B. 柱の穴がずれる・楕円に伸びる**。西の柱の頭の穴が+86〜+122上がる。u21.33の柱`ac212c32`は穴の高さ420→800。原因：`_head`が穴の輪郭（k>0）の制御点まで動かす。直し：`_head`はk>0を動かさない。
- **C. 東の柱の頭に空の穴が残り、桁が柱の木を貫く**（u21〜48、v−1.3）。3e-2で東の桁を約579下げた（z≈6.93k）が、柱の古い穴（z≈7.3〜7.7k）は残る。2階の東の桁（z2720）も柱の穴とvで133〜218ずれる。直し：柱の東の穴も消し、桁は柱の面（t=±90）で切って柱のあいだに架ける。
- **D. 柱が板の厚みの方向にずれ、板に重なる**。u48西`9d55c403` t[−184,−2]、u45西`fe2c527c` t[−186,−5]、u21.33西`ac212c32` t[3,192]、u21.33東`68a6c049` t[−180,95]、u24〜42西 +10〜+16。原因：Phase 2の`move_xy`が厚みの方向にも押す。南の端の124の移動に柱が付いてこない。直し：柱の移動は架構の面の中だけ。南の端の移動は22a〜cをまとめて動かす。
- **E. 2枚の板の輪郭が違う**。u45・u48で面積差0.9 m²、下端が76・101違う、穴の高さも4347と4422。u24〜42は6〜9違う。原因：`_deepen`が板ごとに自分の上のroof_fから測る。直し：一つの架構の2枚は一度だけ作り（2枚のroof_fの低いほう）、もう1枚は厚みの方向に平行に写す。
- **F（生成）. 端の架構の外の板の穴に桁が無い**。u48 t+135、u21.33 t−131、2階u33 t+135。桁が柱の芯で終わる。直し：本館と同じく端の桁を張り出す（GIRDER_OVERHANG 600）、または外の板の穴を作らない。
- **G（生成、7cで悪化）. 斜めの桁が丸い穴を通らない**。西の線の角（u48→45→42、u24→21.33）。桁が穴の中心から90〜180外れる。直し：穴を「その板の面での桁の断面＋10」にする、またはこの2スパンの桁を折る。
- **H. 押し出しの輪郭が壊れている**。東の柱u24・u27・u30（`7cba9bf6`・`d04c2b60`・`76eedd4e`）：外の輪郭がz≈8030で自己交差、v−1.05まで細い尖り（3dの`_face_in`、TOL_F=40が頭の曲線の制御点を引く）。u21.2・u21.47の2階床梁（`b4608c9c`・`6e7e4181`）：Phase 3`_trim`でv−10.24で切り、穴2が45%しか輪郭に入らない、輪郭も自己交差、柱に89届かない。直し：3dは頭の曲線の制御点を動かさない。`_trim`は輪郭の外に出る穴を捨て、床梁は柱まで残す。
- **I. どこにも届かない部材**。
  - 東の柱の頭が梁の上端より64〜98高い（u24〜48）。項1310の件は直っていない。原因は`_head`と、梁の上端の求め方の違い（`_deepen`は板の厚みの真ん中のroof_f、`_zt`はuc±0.132）。
  - 2階の床梁22c（u21〜33）：東の端が柱の面から110出て宙で終わる。西の端は121〜126浮く。
  - 出し梁19枚：内の端が梁から20〜90離れる。u48とu21.33は板1枚で下の端が330浮く。
  - 登り梁u43.5（`5d78b20b`）：東の端1.0 m、西の端0.48 m、何にも触れない。
  - 高窓の帯の窓台・まぐさ（120×180、v−1.11、20本）：両端とも柱まで約59足りない。u48の組はu50.75まで2.4 m伸びる。
  - 階段の箱の柱：u33.9の2本は上に何も無い（1.5 m）、u31.56は0.29 m。
  - 直し：作った後で、各部材の端を最も近い構造材の面まで伸ばすか切る（`cont_final.txt`）。

## 提案
いちばん効く一つの直し：7cの最後に「穴を作り直す」段を置く。各22a・b・cの内側の輪郭を全て消し、その板・柱の真ん中の面で切った22dの断面＋10を穴として足す。これでA・B・C・Gの穴が桁と必ず合う。加えてD（厚みの方向に動かさない）とE（板を一度だけ作って写す）。
