- **→ 更新係（未）**：`draw100.py` の配置図で、外構はこの json を読んで描いてください。
  - `layers`：レイヤー 70〜79 の 1/200 での描き方（線・破線・塗り・樹木）。頭上の屋根（71）とムベの棚（73）は破線。
  - `labels`（37）：文字と位置。`kind` で大きさ（key・name・small・context）。`along` があれば線に沿わせ、無ければ紙に水平（川を下辺に回したあとも水平）。`note` は小さく、省いてよい。
  - `trees`：入江の木・モミジ・ヤマボウシの名前。
  - `parking`：車室5の記号（P×4、搬入×1）。`bikes`：保護者12台・職員9台。
  - `entrance`：公園の木戸の赤い点。`security_line`：セキュリティの線（赤い破線）。`walks`：道すじ（茶の細い破線）。
  - `counts` と `notes`（4行）は図の脇の注に。
  - `omit`：番号の丸・凡例・断面・0〜2歳の家具の番号は配置図に描かない。
  - 周辺の道路と川の名前（西の道路（歩道なし）・北西の道路・公園・高野川）も `labels` の context に入れた。課題の所要（周辺の道路・樹木・河川・駐車スペース）は、これと PLATEAU で足りるはず。
