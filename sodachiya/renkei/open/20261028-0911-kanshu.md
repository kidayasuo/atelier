理由（監修）：今の `draw100.py` はメッシュの版を自前で切り、隠れ線は画像の奥行きで決めるので、細い所・斜め・曲面で線が欠けたり筋が出たりする。Rhino はソリッドから厳密に切断と隠れ線を出し、線は元のレイヤーごとに分かれて Illustrator に渡せる。ただし Rhino は木田さんの Mac でしか動かない（自動の作り直しには入れない）。モデルの誤り（三角形に割れた面など）はそのまま線に出る＝モデルの確かめにもなる。

**更新係（未）**：今の図（`drawings/`・`model/drawings/`）は一つも変えない。足すもの：
1. **`sodachiya/rhino/zumen.py`**（`doko.py` と同じく Rhino 8 の `RunPythonScript`、Python 3・rhinoscriptsyntax。木田さんが `sodachiya.3dm` を開いて一回走らせる）：
   - 図：1階平面（FL+1500 で切る）・西館2階平面（2FL+1000）・断面 B・C・立面 4 面（園庭の側・道路の側・南・北）。見る向きと範囲は `draw100.py` の `SECTIONS`・`ELEV_VIEWS` と同じ値を読む（ファイルに書き写さない。要るなら draw100 が json に書き出す）。断面 A（r=197 m の弧で切って展開）は後回し（スパンごとの平面の切断をつなぐ案）。
   - 切った所：クリッピング平面＋Rhino 8 の断面の線（ClippingDrawings／断面のスタイル）、見えがかり：Make2D（隠れ線を除く）。
   - 線の太さは3つ（JIS、更新係の db8003b の決まりと同じ）：切断 太、見えがかり 中〜細、**想像線（破線）**は平面の「切断より上で示すもの」だけ（屋根・軒の外形、光の筋、越屋根、吹抜の縁、2階の床の縁、遊戯室の上の遊具 82・83、ロフトの上の段、高窓、樹冠。項 20261027-2331 と同じ一覧）。ほかの切断より上の物は描かない。
   - 出す線は元のレイヤーごとのレイヤーに（彩色・太さを Illustrator でレイヤー単位に変えられる）。番号の線（N 番号）・作り直しの印・ロゴの板・部屋の色の板（31〜59 の面積の板）は描かない。
   - 紙の上の置き場所と縮尺を今の図とぴったり同じに：`draw100.py` が図ごとに「3dm の mm → 紙の mm」の json を書き（配置図の `…_xform.json` と同じ形、平面・断面・立面にも）、zumen.py はそれを読んで置く。
   - 書き出し：`sodachiya/drawings_rhino/<図の名前>.pdf`（と .ai か .dwg、Illustrator で開けるもの）。リポジトリに入れるかは木田さんが決める。
2. **`draw100.py` の「文字と寸法だけの層」**：今の図と同じ紙・同じ位置で、部屋名と面積・寸法・通り芯と番号・図名と縮尺・方位・凡例だけを描いた PDF を、図ごとに `…_文字.pdf` として足す（線と塗りは無し）。Rhino の線の上に重ねる。
