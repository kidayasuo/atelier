ユーザー（10-27）：伝令をなくす。決まりは「役割分担」の「自動の作り直し」「連携と受け箱」と、「場所の境目」の下の「小さな直し」。

1. **作り直しは push で自動**（GitHub Actions、`.github/workflows/sodachiya_build.yml`）。`data/`・作り直しのスクリプト・取り込み用ファイルを push すれば、約30分で3dm・図・面積表が `[3dm] 自動の作り直し` で入る。**「作り直し：…」の項を更新係に出さない。** 結果は pull して使う（終わったかは `renkei/log/auto.md`）。止まったら、前の作り直しから commit した係に自動で項が立つ。1回目 0a0da09（たまっていた作り直しの依頼は済になった）。
2. **`--publish` は手で走らせない**（自動とぶつかる）。確かめは今までどおり `--publish` なしで preview に。
3. **知らせは取りに行く**：作業の始めに pull して `python3 renkei/inbox.py mine <自分>`。出た知らせは自動で「読んだ」になる（`--keep`で残す）。受け箱は未だけを出す。
4. **小さな直しは、ユーザーが話しているチャットがその場で**：担当でないデータ・スクリプトでも、数値一つ・注一つのような判断の要らない直しは頼まずに直して push し、担当に知らせ。形・建築の判断が要るものは今までどおり依頼。
5. 更新係へ：「更新係の手順」を、作り直しは自動・更新係は作り直しの仕組みと `draw100.py`・止まったときの手当て、に書き直してほしい。
