# 平らであるべき面の点検：Rhino版で一枚にまとまらない面（solidify.py の許容値）

10-27 20:20　設計監修から。

- ソリッド係：未　planar_regions の許容値を 0.5 mm・1° に（弧の折れはまとめない）

---

ユーザー（10-27）：Rhino で、平らであるはずの所にメッシュの線が見える。監修が全体を点検した（9857ac7 の作り直し）。ソリッド係の分は、元は平らなのに Rhino版で一枚の面にまとまらない所。

1. **平らなのに一枚にならない所が 2131 組**（ずれ 0.5 mm 未満、折れ 2° 未満）。多い順：20 415・24 351・20m 208・21g 178・22t 170・20t 168・21 148・10 115・17 111。
2. **階段の箱の壁（24、u30〜34、v−5.06〜−2.93）**：元は平ら（u33.088 の面は330三角形でずれ 0.0017 mm）。高さ 0.3〜0.4 mm・長さ 120 mm の細い三角形の法線が 0.30〜0.36° ずれ、`solidify.py` の `planar_regions` の COS_PLANE（0.3°）と細い三角形の高さ 0.3 mm に引っかかって、面が z2.40・2.57・2.79・3.20 で切れている。ユーザーの見た「階段の壁の線」はこれ。
3. **許容値の見積もり**（平らであるべきレイヤーの Brep の面の数）：今 6235 → TOL_PLANE 0.5 mm・COS_PLANE 1° で 5811（新しくメッシュで残る物なし）→ さらに細い三角形 3 mm で 5386（24 と 18 に1個ずつメッシュが残る）。2 mm・2° は 11a・23 でかえって増える。**監修の勧めは 0.5 mm・1°**。ただし本館の弧はスパンごとの多角形で折れ 0.84° を曲面にしない決まりなので、折れの前後をまとめないこと（TOL_PLANE が効いていれば 3 m で約44 mm 外れるのでまとまらないはず）を確かめてほしい。
4. 割れ目（17 の 468 組・24 の 45 組・11a の 70 組）の扱い。17 は本館係に二枚の板を一枚にするよう頼んだ。
5. solidify.py は manifold3d と mapbox_earcut が無いと東の壁を全部メッシュにする（setup.sh には入っている）。
