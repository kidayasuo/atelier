# 本館と西館のすき間を先生の道から使う倉庫に

10-25 07:10　設計監修から。

- 西館係：未　すき間の倉庫（南は先生の道、北は遊戯室から）・遊戯室の道具入れの箱をやめる・階段の下の倉庫

- 本館係：未　本館の西の外壁に引き戸（先生の道の側）

- 更新係：知らせ　入ったら作り直し、面積表は自動で倉庫に入る

- 模型作成：知らせ　すき間に棚と戸

- プレゼンの準備：知らせ　倉庫の数

---

ユーザーの決定（10-25、監修と相談）：倉庫は道具入れとして確保した場所を全部数える。今は教材庫10.1＋園庭の小屋の倉庫12.9＝23.0で、課題の約30に足りない。遊戯室の道具入れ5.0は遊戯室（243.5）に数えているので移さない（移すと240を割る）。そこで、**本館と西館のすき間（ホールより北、架構10〜18、u30〜51）を、西吹き抜け（先生の道）の側から使う奥行きの浅い倉庫にする**。今は幅0.55・高さ約4.5の空いたすき間で、床の板も無い（延床に数えていない）。

- **→ 西館係（未）**（10-25 7:40 に書き直した、ユーザー：すき間も倉庫に、中にもすき間に向かない道具の置き場を少し、階段の下は？）：
  - **遊戯室の道具入れ（87、u30〜32・v−12.7、約5.0）の箱をやめる**：遊戯室の床の上にあり、遊べない場所なのに遊戯室の243.5に入っていた（厳密には約238.5で240を割る）。箱を除けば遊戯室は243.5のまま正しい数になる。
  - **すき間の倉庫**（場所の境目で西館係）：床の板（FL±0）と棚。**南の部分 u30〜40 は先生の道の側から**（教材、レイヤー`59_1F_倉庫（すき間、先生の道）`）、**北の部分 u40〜45.6 と u48.1〜51 は遊戯室の側から**（マット・ボール・フープなど立てて掛ける遊具、`59_1F_倉庫（すき間、遊戯室）`、西館の東の壁の下の部分に引き戸）。境目の位置は西館係で決めてよい。口②とその引き戸が走る所は除く。**棚は本館の側だけに留め、西館の壁とは50〜100あける**（エキスパンション）。使える奥行き約0.45、高さ約2.4まで、その上はすき間の空気の道として開けたまま（本館の越屋根の吐き出し → 夏の夜は遊戯室へ）。遊戯室の東の覗き窓（h3.3〜4.3）はそのまま。
  - **階段の下の倉庫**（すき間に向かない大きな道具：平均台・跳び箱・積んだマットなど）：西館の階段（u30〜33・v−2.2〜−5.0）の上の段（西の半分 v−4.6〜−3.4、u30〜32で踊り場から3.09まで上る）と踊り場（u32〜33、h1.645）の下。床 約1.2×3.0＝約3.5、天井の高さは北の端（踊り場の下）約1.5 → 南の端 約2.9。**戸は階段の箱の西の面（v−5.0）、u30.3〜31.8に、遊戯室へ向けて**（そこは上の段の下で約2.0〜2.9の高さがある）。レイヤー`36b_1F_倉庫（階段の下）`、階段の床（36）からその分を除く。
- **→ 本館係（未）**：本館の西の外壁（v−0.35〜−0.20）の **u30〜40（すき間の倉庫の南の部分）** の下の部分に、先生の道へ向けた引き戸（h約2.1、何枚かに分ける）。このすき間は室内なので、この範囲の西の外壁は実際には室内の壁（下の指摘）。plan04ほかの図にも。
- **指摘（本館係・西館係、急がない）**：すき間は室内（決定事項_本館）なので、u21〜51では本館の西の外壁と西館の東の壁の両方が外皮の断熱を持っていて二重になっている。本当の外皮はすき間の蓋と南北の端のガラス。断熱をどちらに置くか（蓋の側に寄せて二つの壁は室内の壁にするか）を二人で決めてほしい。
- 面積表は`areas.py`が`59_1F_倉庫`で始まる床を全部数えるので、上の名前なら自動で入る（教材庫10.1＋すき間 約8＋階段の下 約3.5＋園庭の小屋の倉庫12.9＝約34で、約30を満たす見込み。`areas.py`は`36b_`も倉庫に数える）。
- **模型作成（知らせ）**：すき間に棚と、本館の西の外壁の下に戸（1/100ではほぼ見えない）。
- **プレゼンの準備（知らせ）**：倉庫＝教材庫＋すき間の倉庫＋園庭の小屋の倉庫。講評の種：二つの建物のすき間（エキスパンション）を、先生の道に沿った一続きの教材の棚にした（デッドスペースを残さない）。
