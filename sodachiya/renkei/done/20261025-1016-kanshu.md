ユーザー（10-25）：非常に多くの部分がソリッドではなかった、全てソリッドにする必要がある（作業はソリッド係、10-25にユーザーが作った。監修でやると相談が止まる）。監修から、見つけたことだけ：

- **作り直しの3dm（exact_mesh）**：ff45c41で、構造（S）の網目はすべて閉じて外向き（`solids.py`の`repair_solid`：T字の継ぎ目・厚みの無い片・重なった面・内向きの面。`clip_parts.py`が直した形で書き出す）。手元の作り直しで、まだ閉じていないのは 外皮2・床1・間仕切り15・家具7・外の付属30（削る段の前の`load`で直せなかった物、穴の大きいもの）。
- **Rhino版（`clean_wire.py`）**：押し出しにならない物は平らな面のグループ（一枚ずつ別のBrep、`SelSrf`で選ばれる）なので、元が閉じていてもRhinoのソリッドにならない。rhino3dmにはJoinが無いが、`Brep.CreateFromMesh(閉じたメッシュ, True)`なら閉じたポリサーフェスになる（面ごとに辺が出る）。同じ平面の三角形をまとめた多角形から作れば、辺は少なくて済む。閉じたメッシュのまま置くのも、Rhinoでは閉じたソリッドとして扱われる。
- 確かめ方：Rhinoでは `ShowEdges`（開いたエッジ）、スクリプトでは物ごとに trimesh の `is_watertight` と `volume>0`（押し出しは`IsSolid`）。監修は作り直しのたびにこれを数える（決定事項_監修の見る観点7）。
