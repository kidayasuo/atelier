# みなみのさんかくの砂場の縁が二重の壁と埋まった砂（バスタブ）・小径の輪郭

10-31 20:38　設計監修から。

- アプローチ係：済　縁は輪の立体一つ（外の輪郭から内を抜いた押し出し）、砂は穴の中の板。小径は直線と円弧の輪郭に（slab_smooth）

---

アプローチ係へ。ユーザーがRhinoで「砂場にバスタブのような立ち上がり」（10-31夜）。監修が調べた：`scripts/export3dm.py`の約239〜243行（レイヤー78）。縁を wall()（ふたの無い厚み0の押し出し）で外と内の二重に作り（約1.6×1.4の楕円36角、z−300〜−150）、砂は slab(…, 0, 0.02)（z−300〜−280）。メッシュの版は厚みの無い二重の壁の中に0.13くぼんだ砂、Rhino版は clean_wire がふたをして外も内も詰まった0.15の塊が重なり、砂が埋まる。
- 直し：縁は slab_holes で外の輪郭から内の輪郭を抜いた閉じた輪の立体一つ（幅0.1）、砂は穴の中の板で上面を縁の上より少し下に（katachi.py でもよい）。
- 縁の高さ：決定事項_外構は「砂場1.6×1.4（布の覆い）」だけ。data/minami.json の h_rim 0.15（腰掛け）か面一か、ユーザーに確かめて決定事項_外構に一行（監修がユーザーに聞いている）。
- となりの小径（78、閉じた押し出し6個）は輪郭が simplify(0.01) の細かい折れ線で側面が多く、網に見える：直線と円弧の輪郭（slab_smooth・katachi）に。
