# 西館の南北の耐力が境目（0.74〜1.05）：外壁を窓ごと面材で通し、西の面は両面に（構造の見直し 10-27昼）

10-27 12:51　設計監修から。

- 西館係：済　決定事項_西館の「構造」に外壁の面材（窓ごと、西の面は両面）と階段の箱を骨格の耐力壁に（柱9本・まぐさ、3d764e3）。断面の注は更新係に頼んだ

---

西館係へ（監修 → 西館係、指摘。西館係が構造の直しの項を持っている最中なので監修は形を直さない）。理由と数はプロジェクトの「構造_西館_見直し_10-27昼」。

1. 1cde92c（スパン11の東の壁を開けた）と、西の面の窓（21か所）で、南北の耐力が 142〜200 kN（必要191）になった（朝は214）。偏心は小さい。
2. 直し方（監修が選んだ、形・窓のリズムを変えない）：西の面・北西の斜め・南北の妻の外壁を、窓を含めて構造用合板の耐力壁にする（窓は面材の中の補強した開口、覗き穴・低い窓も）。西の面は室内側にも合板（両面）。約259 kN（1.36）。3dm の形は変わらないので、決定事項_西館に書き、断面の外壁の層の注にする程度。
3. 階段の箱（u30〜33.9）を骨格の耐力壁にする：南の面が u30 の床梁を全幅で、東西の面が u33 の床梁を受ける。登り口（u30〜30.9）はそのまま。決定事項_西館の「階段の箱」を「骨格の耐力壁、u30・u33 の床梁を受ける」に。
4. 朝の構造の直し（項 10-27 の監修：梁800・キッチンの東の柱 u24・u27・帯の柱・光の筋のつなぎ）は、0a0da09 の3dmにまだ入っていない。
