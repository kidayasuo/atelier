- 押し出しになるのは「向かい合う平らな面＋垂直な側面」だけ（`process` の `as_prism`）。それ以外は平面ごとのトリム平面に分けている。

## 分かったこと（ここの道具の限界）
- **rhino3dm（Python）には面をつなぐ（Join）・ブール演算・面の追加が無い**。Brep を作れるのは `CreateFromBox`・`CreateFromSurface`（1面）・`CreateTrimmedPlane`（1面）・`CreateFromMesh` など。
- `Brep.CreateFromMesh(mesh, True)` は閉じた立体（`IsSolid` True）を作るが、辺の許容差が未設定で `IsValidWithLog` が False（`edge.m_tolerance=-1.23e+308`）。三角形ごとに面になり、曲面はファセットのまま。最後の手段。
- **`Extrusion` は閉じた立体を正しく作れる**：輪郭は円弧を含む `PolyCurve`（`Arc(...).ToNurbsCurve()` を `Append`）でよく、穴は `AddInnerProfile`、`Create(planarCurve, height, cap=True)` は輪郭の面の法線の向き（負の高さで反対）に押し出す。鉛直の面に描いた輪郭なら水平に押し出せる（`IsSolid` True・`IsValid` True を確かめた）。**曲線を曲線のまま、穴あきの立体にできるのはこれ**。
- openNURBS（C++）を作業場でビルドして Brep を面・辺から組む案は、外のコードの実行として止められた（許可が要る）。ON_Brep のバイナリ（`Encode`/`Decode`）を Python で書く案は可能だが大きい。

## 方針の案（更新係の考え、新しいチャットで決めてよい）
メッシュの一片（閉じた片）ごとに、押し出しの組に分けて置き換える（`south/solidify.py` を新しく、`clean_wire.py` から呼ぶ）。
1. **向きのある押し出し**：一番大きい面の法線 d に対して、全部の面の法線が d に平行か直角なら、d に直角な面で切った輪郭を d の向きに押し出す（梁・板・傾いた屋根の板・ガラスの蓋・まっすぐな壁（開口は穴）・妻壁（輪郭が五角形））。
2. **鉛直に積む押し出し**：面が全部「水平か鉛直」なら、水平の面の高さで区切り、区間ごとに中ほどで切った断面を押し出して積む（曲がった外壁の開口は、高さの区間ごとの断面の違いで表れる。柱の頭の膨らみなど）。同じ断面の区間はまとめる。
3. **輪郭の円弧**：輪郭の多角形で、短い辺が続き頂点が一つの円に 1 mm 以内で乗る所を円弧に（3点の円弧）。本館は中心 `C`・半径 205 m 前後の弧、西館の角は R3.1 など。
4. **確かめ**：押し出しの体積の和がメッシュの体積と 0.5% 以内で合うか。合わなければ次の方法へ。
5. **残り**（西館のねじれた屋根・屋根に沿う天端の壁など）：西館の屋根は `ruled_roof.py` の線織面を、放射の線ごとの粗い四角形のメッシュにして `CreateFromMesh`。それ以外は `CreateFromMesh`（ファセット、辺の許容差が未設定）か、Rhino の中で一度だけ回すスクリプト（`JoinBreps`・`MergeCoplanarFaces`）を用意してユーザーに頼む。
- 一つの壁が積んだ押し出しの複数の立体になるのはよい（グループにまとめる）。
- 外壁（17・21）は `clip_parts.py` でレイヤーごとに一つの物にまとめてある（`merge_21`・`merge_17`）。Rhino版では、まとめる前の片の方が押し出しにしやすい（まとめるのはメッシュの版だけにする、など）。
