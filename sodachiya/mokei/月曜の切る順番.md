# 月曜（11-02）の切る順番とファイルの一覧

火曜（11-03）はレーザーが使えない。接着する物・骨組みを月曜に切り、周辺の物は水曜でもよい。時間は切る線の長さからの目安（速度は仮定を含む）。

## 設定

| 材 | 速度/出力 | 備考 |
|---|---|---|
| 航空ベニヤ0.8 | 40/13% | 切った実績あり |
| シナ1.7 | 20/13% | 切った実績あり |
| シナ3.0 | 12/19%（16%で切れ残りがあった。いま切っている板は2回なぞる） | 16%は切れ残りあり |
| 彫り（全材） | 速度123、出力12%・最小4% | 最小を下げると、速度の落ちる端が貫通しない（0.6で確認） |
| 航空ベニヤ0.6 | 40/10% | T5で確認（3段とも抜けた。いちばん弱い10%） |
| 航空ベニヤ1.0 | 40/14% | T6で確認（3段とも抜けた。いちばん弱い14%） |

合計の切る時間は約35分（材の入れ替えを除く）。

## 切る前の確かめ

- 航空ベニヤ0.8の在庫（07で300×600を1枚）
- 航空ベニヤ1.0の予備（14wと予備で300×600を2枚ぶん）
- シナ1.7（12w、06c）の残り
- 台を運ぶ発泡ボード（A1）

## 水曜でよい物

- 西館の屋根（11a/11b_西館の屋根は10-27の古いデータ。越屋根なしで作り直す）
- 縁側のガラス戸・鴨居、南の妻のガラス・格子（彫り0.4）、家具の箱、遊戯室の物、縦格子の彫り
- 駐輪・舗装・護岸の線（重要）

## 手作業

- 本館3〜5歳の教室の丸い床の窪み3つ（φ約2.4 m）をノミで掘る（時間があれば）
- 西館の摺鉢の底（基礎の切り抜き片、φ32、深さ2 mm）をノミで
- 溝のない足（本館6・西館3）の位置だけ、1/1の平面を紙に印刷して針で床に印す（室内の壁_位置表.md）
- 切り株（針金＋フェルト）、北山杉の林（針金約40本）、川の彫り、主要な木の穴あけ印

## 気になる点

- 西館の南東の柱1本（u21.33、v−1.42）は穴から約11 mm外。床がないので表面に直接立てる
- 穴の縁とほぞ穴の間が0.5〜0.6 mmと薄い所が2か所（u50.57 v−6.25、u21.33 v−10.29）
- 公園側の塀の足の溝が4か所で重なる（重要の側なので後回し）
- 14wの東面の上の帯は1.5 mmの柱でつながる。弱ければ上下に分ける
- 07の2階の床梁は12本から10本になった。理由は未確認
