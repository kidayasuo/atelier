# 育ち舎　1/100 模型

担当：模型作成のチャット。寸法は `../data/mokei.json`、レーザー用のデータ（DXF）はこのフォルダに出す。3dm（`../model/sodachiya_exact_mesh.3dm`）は読むだけ。

## 考え方

- **分解できる模型**。下から 桟 → 中の層 → 表面（GL）→ 建物。建物は布基礎ごと表面の穴にはめるだけで、接着しない。外す順番（屋根 → 桁 → 架構 → 床 → 布基礎）を逆にたどると建て方になる。
- **色は木とオフホワイトだけ**。緑は使わない。場所の違いはレーザーの線の模様で描き分ける（畑＝平行線、砂場・水浴び場＝点、小径・テラス＝板の目地）。
- プラスチックを減らす（スチレン・ハニカムは使わない）。

## 層（台からの高さ、mm）

| 層 | 材 | 高さ |
|---|---|---|
| 桟（枠） | シナ 3 を縦に使う | 40（崖の高さ） |
| 中の層 | シナ 3（ほぞ穴だけ） | +3 |
| 表面＝GL | シナ 3（建物の外形を抜く） | +6 |
| 布基礎 | 表面から抜けたシナ 3、中の層の上 | 上面＝GL |
| 床 | シナ 1.7×2（土足は上の層を抜く、受け取り土間は 2 層とも抜く） | GL+3.4 |
| 柱 | 0.8×2。肩が GL（布基礎の上面）に乗る。ほぞは布基礎＋中の層に差す（6 以下） | |
| 屋根 | シナ 1.7×2（下の層は室内の上だけ、位置決め） | |
| 道路 | シナ 3＋1.7＋NTラシャ 1 | GL−0.3 |

## 崖（高野川）

写真：プロジェクトの IMG_8144・8146・8147・8148。上から、柵の土台のコンクリートの立ち上がり → 小段（コンクリートの天端）→ 谷積みの石積み（垂直に近い）→ 河川敷。高さ 5 m、土が積もって 4 m の所が多い（10-21 実測）。

模型では川側の桟がそのまま護岸。KROMA 1 mm に 45° の格子の目地を刻んで傾けて立て、上に小段と立ち上がりの帯。机の上が河川敷。

## 材料（10-21 時点）

持っているもの：航空ベニヤ 0.4×1・0.6×2・0.8×3・1.0×4・2.0×3、シナ A1 1.7×2・3×1、PET A2 0.3×3・0.5×1、平竹ひご 2×4×7・2×5×1、ジオラマの砂利、ファンド、接着剤と道具一式、ピアノ線のカッター。

注文中：航空ベニヤ 0.4×1・0.6×1・0.8×1・1.0×2、シナ A1 1.7×1・3×3、白木丸棒 2 mm、丸竹ひご 1.8 mm×14、モデリングウォーター、ヒノキ角材 2 mm×2・3 mm×2・5 mm×1、KROMA A2 1 mm×1・2 mm×1、NTラシャボード（グレー）A2×2、トゥリーク、かすみ草（白）。

ほかに：ピアノ線 0.5〜1.0、メタルプライマー、平刀（3〜5 mm）、チュールと刺繍糸（手芸店）。

## 作業の順番

1. **試し切り**（最初の日）：柱のほぞ穴の幅 4 種、桁の長円の穴 4 種、床の柱の穴、KROMA の目地の出力。ノギスで板の実際の厚さを測ってから決める。
2. **台**：桟、中の層、表面（敷地の外形・建物の穴・ほぞ穴・線の模様）。
3. **架構を 1 本だけ試作**してから、本館 20 本・西館を量産。
4. 床・布基礎 → 架構を立てる → 桁を通す → 壁・家具 → 屋根。
5. 外構：道路、崖、小川、樹木、北山杉の林。
